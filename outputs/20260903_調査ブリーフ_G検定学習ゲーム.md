### 背景事実

#### 1. G検定の定義・主催・目的（JDLA公式）

- **通称**: G検定（ジェネラリスト検定）。
- **正式名称（公式表記）**: `JDLA Deep Learning for GENERAL`。依頼文の「GENERALIST」は通称由来の言い換えであり、公式英語名は **GENERAL**。出典: https://www.jdla.org/certificate/general/ 、https://www.jdla.org/news/20251008001/
- **主催**: 一般社団法人日本ディープラーニング協会（JDLA / Japan Deep Learning Association）。設立日 2017年6月1日。理事長は松尾豊（東京大学大学院工学系研究科 教授）。出典: https://www.jdla.org/about/
- **JDLAの設立目的**: 「ディープラーニングを中心とする技術による日本の産業競争力の向上」。活動領域は産業活用促進、人材育成、公的機関や産業への提言、国際連携、社会との対話。出典: https://www.jdla.org/about/
- **G検定の定義（公式）**: 「一般社団法人日本ディープラーニング協会（JDLA）が実施する、AI・ディープラーニングの活用リテラシー習得のための検定試験」。受験対象は「AI・ディープラーニングに関わる全ての方」。出典: https://www.jdla.org/certificate/general/
- **検定する能力（公式概要文）**: 「ディープラーニングの基礎知識を有し、適切な活用方針を決定して、事業活用する能力や知識を有しているかを検定する」。出典: https://www.jdla.org/certificate/general/
- **学習を通じて得られる理解（公式）**: 「AIで何ができて、何ができないのか」「どこにAIを活用すればよいか」「AIを活用するためには何が必要か」。出典: https://www.jdla.org/certificate/general/
- **対象人材の位置づけ**: JDLAは「事業活用する人材（ジェネラリスト）」向けがG検定、「実装する人材（エンジニア）」向けがE資格、と対で定義している。出典: https://www.jdla.org/certificate/
- **第1回実施**: 2017年12月。出典: https://www.jdla.org/news/20251008001/
- **資格証明の年号付与**: ディープラーニングは日進月歩のため、合格後の資格証明に実施年号を付与する。年号なしロゴは配布しない。出典: https://www.jdla.org/certificate/ 、https://www.jdla.org/g-qa/
- **関連位置づけ**: 経済産業省オブザーブ「Di-Lite」推奨AI資格。G検定合格はデジタルリテラシー協議会の「DX推進パスポート」（ITパスポート・DS検定リテラシーレベルとの組合せ）の対象試験の1つ。出典: https://www.jdla.org/certificate/general/ 、https://www.dilite.jp/passport
- **受験資格**: 制限なし。試験は日本語表記のみ。出典: https://www.jdla.org/g-qa/

#### 5. 初心者がつまずきやすい論点

公式が「苦手分野ランキング」を出しているわけではない。以下は公式アンケート・公式改訂趣旨・公式例題の出題領域と、合格者談話に根拠がある論点。

**生成AI / LLM**
- 2024シラバス改訂の中心が「基盤モデルや言語モデルといった生成AIに必要となる技術の追加」。出典: https://www.jdla.org/news/20240514001/
- 公式例題にスケーリング則、zero-shot Learning 等が含まれる。出典: https://www.jdla.org/certificate/general/issues/
- 用語が新しく、Transformer / Attention / RLHF / 拡散モデル / 基盤モデルを混同しやすい、は二次情報で繰り返し指摘。出典（二次）: https://craftai.jp/g-kentei-new-syllabus-2026-guide/ 、https://note.com/kenji20251123/n/nfa8fe1097273
- **注意**: 生成AI特化の別試験「Generative AI Test」があり、G検定は生成AIを含むAI・DL全般。出典: https://www.jdla.org/certificate/generativeai/

**法律・倫理**
- 公式が独立の大分野として明示（個人情報保護法、著作権法、契約、AI倫理・ガバナンス）。出典: https://www.jdla.org/certificate/general/
- 公式例題に個人情報の該当性、開発契約・NDAの時期、顔認識の公平性、学習電力と環境が含まれる。出典: https://www.jdla.org/certificate/general/issues/
- 条文番号・制度名（著作権法30条の4、GDPR、営業秘密の三要件、ソフトロー／ハードロー、リスクベースアプローチ）は暗記負荷が高い、は二次情報。出典（二次）: https://craftai.jp/g-kentei-new-syllabus-2026-guide/
- 公式推奨書に『ディープラーニングG検定（ジェネラリスト）法律・倫理テキスト』がある。出典: https://www.jdla.org/certificate/general/

**数理・統計**
- シラバス2024で独立項目「AIに必要な数理・統計知識」。出典: https://www.jdla.org/certificate/general/
- 公式例題に相関係数／偏相関係数／共分散／分散の対応、期待値がある。出典: https://www.jdla.org/certificate/general/issues/
- 公式合格者談話: 「機械学習のモデルの理解。高校数学の知識が必要であるが、忘れていることが多かった」。出典: https://www.jdla.org/certificate/general/start/
- 公式インタビュー: 文系合格者が「歴史や時事は理解しやすいが、計算問題や理系的な概念はテキストだけではすぐに理解できなかった」。出典: https://www.jdla.org/topic/g-interview26/
- 二次情報: ベイズ、確率分布、線形回帰、勾配降下法が説明なしで出る、との指摘。出典（二次）: https://www.brush-up.jp/theme/it/ai/sub/g-kentei

**歴史・年号・固有名**
- 公式例題に第1次／第2次AIブームとエキスパートシステム、2015年ILSVRCとResNetがある。出典: https://www.jdla.org/certificate/general/issues/

#### 6. 著作権上の注意（学習ゲーム作問）

##### 人工知能とは
- **人工知能（AI）**: 人間の知的作業をコンピュータで行わせようとする技術・研究分野の総称。
- **機械学習**: データから規則やパターンを自動で獲得するAIの中核手法。
- **ディープラーニング（深層学習）**: 多層ニューラルネットワークで特徴をデータから学習する機械学習の一分野。
- **エージェント**: 環境を感知し、目標に向かって行動を選ぶ主体。
- **AI効果**: 実現した技術が「単なる自動化」に見え、AIと呼ばれなくなる現象。
- **強いAI / 弱いAI**: 人間並みの汎用知能を目指す立場と、特定タスクの知能的振る舞いを目指す立場。
- **シンギュラリティ**: AIが人間の知能を超え、社会が予測困難に変化するという仮説的時点。
- **フレーム問題**: 有限の計算資源では、現実の「関係する情報」を切り出せない、という古典的難題。
- **シンボルグラウンディング問題**: 記号（単語）を実世界の意味に結びつけられない、という問題。
- **身体性**: 知能は身体と環境との相互作用なしには成立しにくい、という議論。
- **知識獲得のボトルネック**: 専門家の知識をルールとして書き出すコストが、実用化を阻むこと。
- **トイ・プロブレム**: 単純化した玩具的問題では解けても、現実問題に汎化しないこと。
- **チューリングテスト**: 対話だけで人間と機械を区別できるかを問う知能の操作的試験。
- **中国語の部屋**: 記号操作だけでは「理解」したことにならない、とする思考実験。
- **ダートマス会議**: 1956年、人工知能という語が研究分野として掲げられた会議。
- **ローブナーコンテスト**: チューリングテスト的な会話プログラムを競うコンテスト。

##### 人工知能をめぐる動向（探索・知識・歴史）
- **探索木**: 可能な手や状態を枝分かれで列挙する探索の表現。
- **幅優先探索 / 深さ優先探索**: 同階層を先に広げる探索と、一本の先を深く進む探索。
- **Mini-Max法**: 対戦で自分は最大、相手は最小になる手を仮定して読む探索。
- **αβ法**: Mini-Maxで明らかに不利な枝を枝刈りし、計算を減らす手法。
- **ブルートフォース**: 可能な手を力任せに総当たりする探索。
- **モンテカルロ法**: 乱数シミュレーションで評価する近似手法（ゲームAIでも使用）。
- **ハノイの塔 / STRIPS / SHRDLU**: 古典的な探索・計画・自然言語理解の研究事例。
- **エキスパートシステム**: 専門家の規則を知識ベースに置き、推論で助言する第2次ブームの中核。
- **MYCIN / DENDRAL**: 医療診断・化学分析の代表的エキスパートシステム。
- **ELIZA**: 単純なパターン応答でカウンセリング風対話を装った初期プログラム。
- **意味ネットワーク / オントロジー**: 概念間の関係をグラフや体系として表す知識表現。
- **is-a / has-a / part-of**: 上位下位・所有・部分全体といった基本関係。
- **Cycプロジェクト / セマンティックWeb**: 大規模常識知識やWeb意味付けの試み。
- **ワトソン / 東ロボくん**: 質問応答・大学入試を題材にした大規模AIプロジェクト。
- **次元の呪い**: 特徴次元が増えるとデータが疎になり、学習が急激に難しくなる現象。
- **ビッグデータ**: 従来手法では扱いづらい規模・多様性のデータが、機械学習を後押しした背景。
- **ImageNet / ILSVRC**: 大規模画像データセットと、それを用いた物体認識コンテスト。
- **LeNet / ネオコグニトロン**: 初期の畳み込み的ニューラルネットワークの源流。
- **AlphaGo**: 深層学習と探索を組み合わせ、囲碁で人間トップに勝ったシステム。

##### 機械学習の概要
- **教師あり学習**: 入力と正解ラベルのペアから、予測関数を学ぶ枠組み。
- **教師なし学習**: ラベルなしデータから、構造・群・圧縮表現を見つける枠組み。
- **強化学習**: 報酬を手がかりに、環境との試行で行動方針（方策）を学ぶ枠組み。
- **分類問題 / 回帰問題**: カテゴリを当てる課題と、連続値を当てる課題。
- **線形回帰 / 重回帰分析 / ロジスティック回帰**: 直線（平面）で数値予測する手法と、確率でクラスを予測する手法。
- **自己回帰モデル（AR） / VAR**: 過去の自分（複数系列）から将来を予測する時系列モデル。
- **決定木 / ランダムフォレスト**: 分岐ルールの木と、それを多数集めたアンサンブル。
- **SVM / カーネルトリック**: マージン最大化で境界を引き、非線形にも写像で対応する手法。
- **勾配ブースティング / AdaBoost / バギング**: 弱学習器を順に補正、または並列に集めて精度を上げる手法。
- **アンサンブル学習**: 複数モデルの予測を組み合わせ、単体より安定・高精度を狙う考え方。
- **k-means / 階層クラスタリング（ウォード法）**: 代表点で分割するクラスタリングと、距離で樹形にまとめるクラスタリング。
- **デンドログラム**: 階層クラスタリングの樹形図。
- **主成分分析（PCA） / 特異値分解（SVD） / t-SNE**: 次元削減・可視化の代表手法。
- **トピックモデル / LDA**: 文書を潜在トピックの混合として分解する手法。
- **協調フィルタリング / コンテンツベースフィルタリング**: 「似た人の好み」と「アイテムの属性」で推薦する二大手法。
- **コールドスタート問題**: 新規ユーザ・新規アイテムでは推薦の材料が足りない問題。
- **マルコフ決定過程**: 状態・行動・報酬・遷移で強化学習問題を数理化する枠組み。
- **Q学習 / 方策勾配法 / Actor-Critic**: 行動価値を学ぶ手法、方策を直接学ぶ手法、両者を併用する手法。
- **ε-greedy / UCB / バンディット**: 探索と活用のバランスを取る行動選択の基本。
- **過学習**: 訓練データに適合しすぎて、未知データで精度が落ちること。
- **汎化性能**: 未見データでも使える性能。
- **ホールドアウト / k分割交差検証**: データを分けて汎化を見積もる検証法。
- **混同行列**: 正解と予測の組合せ（TP/FP/TN/FN）を数える表。
- **正解率 / 適合率 / 再現率 / F値**: 分類の基本指標（全体正答、正と予測した精度、取りこぼしの少なさ、その調和）。
- **ROC曲線 / AUC**: しきい値を動かしたときの分離性能を曲線と面積で見る指標。
- **MSE / RMSE / MAE**: 回帰の誤差を二乗・平方根・絶対値で測る指標。
- **AIC / BIC / オッカムの剃刀**: 当てはまりと複雑さのバランスでモデルを選ぶ規準・考え方。

##### ディープラーニングの概要
- **パーセプトロン / 多層パーセプトロン**: 単純な線形分類器と、隠れ層を重ねたニューラルネットワーク。
- **入力層 / 隠れ層 / 出力層**: データの入口、中間表現、予測の出口。
- **CPU / GPU / TPU**: 汎用計算、行列演算向きの並列計算、学習専用アクセラレータ。
- **活性化関数**: 非線形を入れて、深いネットが複雑な関数を表せるようにする変換。
- **ReLU / Leaky ReLU / シグモイド / tanh / ソフトマックス**: よく使う活性化（後者は確率分布化にも使用）。
- **勾配消失問題**: 層が深いと勾配が消え、前層が学習できなくなる問題。
- **交差エントロピー / 平均二乗誤差 / KL情報量**: 分類・回帰・分布間のずれを測る損失。
- **Contrastive Loss / Triplet Loss**: 似たもの同士を近づけ、違うものを遠ざける損失。
- **正則化 / L1 / L2 / ドロップアウト**: 過学習を抑える制約や、学習時にユニットをランダム無効化する手法。
- **ラッソ回帰 / リッジ回帰**: L1・L2正則化を付けた線形回帰。
- **誤差逆伝播法**: 損失の勾配を出力側から入力側へ連鎖律で伝える学習計算法。
- **勾配爆発 / 信用割当問題 / 連鎖律**: 勾配が大きくなりすぎる問題、功績の分配問題、微分の合成法則。
- **勾配降下法 / SGD / ミニバッチ学習**: 勾配の逆方向にパラメータを更新する基本と、その確率的・小集団版。
- **学習率 / エポック / イテレーション**: 更新幅、全データを見終える単位、更新1回の単位。
- **Adam / AdaGrad / RMSprop / モーメンタム**: 学習率を適応的に調整する最適化手法群。
- **局所最適解 / 大域最適解 / 鞍点**: 近くでは最良、全体で最良、勾配ゼロだが峠のような点。
- **早期終了**: 検証誤差が悪化し始めたら学習を止めて過学習を防ぐ。
- **ハイパーパラメータ / グリッドサーチ / ランダムサーチ**: 人が決める設定値と、その探索法。
- **ノーフリーランチの定理**: あらゆる問題で常に最良、という学習アルゴリズムは存在しない、という定理。

##### ディープラーニングの要素技術
- **全結合層**: 前層の全ユニットと結合する基本層。パラメータ数が増えやすい。
- **畳み込み層（CNN）**: 小さなフィルタを滑らせ、画像などの局所特徴を共有重みで抽出する層。
- **カーネル（フィルタ） / 特徴マップ / ストライド / パディング**: 抽出器、その出力、移動幅、端の埋め。
- **Depthwise Separable Convolution / Dilated (Atrous) Convolution**: 計算を減らす分解畳み込みと、隙間を空けて視野を広げる畳み込み。
- **バッチ正規化 / レイヤー正規化 / インスタンス正規化 / グループ正規化**: 内部の値の尺度を揃えて学習を安定させる層。
- **最大値プーリング / 平均プーリング / GAP**: 領域の代表値を取り、位置ずれに強くしたりサイズを調整する操作。
- **スキップ結合 / ResNet**: 層を飛び越えて足し、深いネットでも勾配を通しやすくする構造。
- **RNN / LSTM / GRU**: 系列を隠状態でつなぐネットと、忘却・入力ゲートで長期依存を扱う改良。
- **BPTT / 教師強制 / 双方向RNN**: 時間方向の逆伝播、正解を次入力に使う学習、前後文脈の併用。
- **Attention / Self-Attention / Multi-Head Attention**: 重要な箇所に重みを置く機構、自分自身への注意、複数視点の注意。
- **Transformer**: Attention中心で系列を処理する、現在の言語・画像モデルの基盤構造。
- **位置エンコーディング / Query-Key-Value**: 語順情報の注入と、検索に見立てた注意の計算。
- **Seq2Seq**: 系列を別系列に変換するEncoder-Decoder型。
- **オートエンコーダ / VAE**: 入力を圧縮して復元するネットと、分布を学ぶ生成版。
- **データ拡張**: 反転・切出し・Mixup・言い換え等で訓練データを水増しし、汎化を上げる。

##### ディープラーニングの応用例（生成AI含む）
- **一般物体認識 / 物体検出 / セグメンテーション**: 何が写るか、どこにあるか、画素単位で領域を分ける課題。
- **AlexNet / VGG / GoogLeNet / ResNet / YOLO / Faster R-CNN / U-Net / ViT**: 画像認識史の代表モデル（分類・検出・医用セグメンテーション・Transformer画像）。
- **形態素解析 / 構文解析 / 分散表現 / word2vec / TF-IDF / N-gram**: 言語を語・構造・ベクトル・統計で扱う古典〜現代の基礎。
- **LLM（大規模言語モデル）**: 大量テキストで事前学習した、生成・理解の汎用言語モデル。
- **GPT / BERT / ChatGPT**: 左から生成する系列モデル、双方向の理解モデル、対話に調整した応用。
- **スケーリング則**: データ・計算量・モデル規模を増やすと性能が予測可能に伸びる、という経験則。
- **RLHF**: 人間の好みで報酬モデルを作り、言語モデルを対話向けに調整する手法。
- **zero-shot / few-shot / 自己教師あり学習**: 追加学習なし、少数例、ラベルなし代理タスクで学ぶ方法。
- **破壊的忘却**: 新しいタスクを学ぶと、以前の能力が落ちること。
- **GAN / Diffusion Model / NeRF**: 敵対的生成、ノイズ除去で画像を作る拡散、3D場面を場として表現する手法。
- **基盤モデル / マルチモーダル / CLIP / Text-to-Image**: 幅広いデータで事前学習し、画像とテキストなど複数模态を扱うモデル。
- **XAI / Grad-CAM / SHAP / LIME**: 予測根拠を人に説明する技術群。
- **量子化 / プルーニング / 蒸留 / エッジAI**: 軽量化（ビット削減、枝刈り、小さい生徒モデル、端末実行）。
- **音声認識 / 音声合成 / MFCC / WaveNet / CTC**: 声を文字に、文字を声に、その特徴とモデル。
- **DQN / PPO / sim2real**: 深層強化学習の代表と、シミュレータから実世界へ移す課題。

- **CRISP-DM / MLOps**: データ分析の標準工程と、学習モデルの継続運用の仕組み。

##### 数理・統計
- **平均 / 中央値 / 最頻値 / 分散 / 標準偏差**: 中心とばらつきの基本統計量。
- **共分散 / 相関係数 / 偏相関係数**: 共変の強さ、標準化した直線関係、他変数の影響を除いた相関。
- **疑似相関**: 見かけ上相関するが、第三要因などで因果ではない関係。
- **確率変数 / 確率分布 / 期待値**: 値が確率で決まる量、その法則、平均的に見込まれる値。
- **正規分布 / ベルヌーイ分布 / 二項分布 / ポアソン分布**: よく使う連続・離散の分布。
- **条件付き確率 / 最尤法 / 最小二乗法**: 条件つきの確率、最も尤もらしいパラメータ推定、誤差二乗を最小にする当てはめ。
- **帰無仮説 / 対立仮説**: 「差がない」を出発点にする仮説と、主張したい仮説。
- **コサイン類似度 / ユークリッド距離 / マハラノビス距離**: 向きの類似、直線距離、分散を考慮した距離。
- **外れ値 / 移動平均**: 極端値と、滑らかにならす時系列処理。

##### 法律と契約
- **個人情報 / 個人データ / 個人識別符号 / 要配慮個人情報**: 識別できる生存者情報、データベース等で扱う個人情報、生体・番号等、取扱いに特に配慮する情報。
- **匿名加工情報 / 仮名加工情報**:  identifiability を下げて利活用しやすくする制度上の加工類型。
- **第三者提供 / 利用目的 / 委託**: 本人以外への提供、目的内利用、処理の外部委託。
- **GDPR**: EUの包括的な個人データ保護規則。域外適用があり得る。
- **著作物 / 創作性 / 著作権侵害**: 思想感情の創作的表現、創作性の要件、無断利用。
- **AI生成物**: 人の創作的寄与の有無によって著作物性が論点になる生成結果。
- **著作権法30条の4**: 情報解析等、著作物に表現された思想感情を享受しない利用についての規定（制度趣旨の理解がシラバス目標）。条文の現行解釈は作問時に一次資料で要確認。
- **特許 / 新規性 / 進歩性 / 職務発明**: 発明の独占権、新しさ、容易想到でないこと、業務上の発明の帰属。
- **営業秘密（三要件）**: 秘密管理性・有用性・非公知性を満たす情報を不正競争防止法で保護。
- **限定提供データ**: 限定された相手に提供されるデータを不正取得等から守る制度。
- **独占禁止法（競争制限・公正阻害）**: AI連携やデータ囲い込みが競争を歪めないかの論点。
- **NDA / 請負 / 準委任 / 精度保証**: 秘密保持、完成義務、善管注意、精度をどこまで約束するか。
- **経済産業省「AI・データの利用に関する契約ガイドライン」**: アセスメント・PoC・開発・追加学習など段階的契約の考え方。
- **SaaS / 利用規約 / データ利用権**: クラウド提供、約款、学習データや生成物の権利配分。

##### AI倫理・AIガバナンス
- **ハードロー / ソフトロー**: 法令による強制と、指針・原則などの柔軟な規範。
- **リスクベースアプローチ**: リスクの大きさに応じて規制・管理の強さを変える考え方。
- **プライバシー・バイ・デザイン**: 設計段階からプライバシー保護を組み込む考え方。
- **アルゴリズムバイアス / サンプリングバイアス / センシティブ属性**: 不公平な出力、データ偏り、配慮すべき属性。
- **Adversarial Examples / データ汚染 / モデル窃取**: 入力の微小改変で誤認識させる攻撃、学習データの汚染、モデルの盗用。
- **セキュリティ・バイ・デザイン**: 後付けではなく設計時から安全を組み込む。
- **ディープフェイク / フェイクニュース**: 偽の音声映像と、虚偽情報の拡散。
- **説明可能性 / ブラックボックス / データの来歴**: なぜその判断か、中身が見えない問題、データの出所追跡。
- **エコーチェンバー / フィルターバブル**: 同じ意見だけが反響する状態と、推薦が視野を狭める状態。
- **モデル学習の電力消費**: 大規模学習の環境負荷。
- **倫理アセスメント / 人間の関与 / トレーサビリティ / 再現性**: 事前評価、人の監督、追跡可能性、再実行できること。
- **AIポリシー / ダイバーシティ**: 組織の利用方針と、多様な視点をガバナンスに入れること。
