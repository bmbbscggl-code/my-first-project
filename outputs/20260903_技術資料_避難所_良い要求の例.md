# 避難所システムの良い要求の例（日本語）

> **この資料の目的**: INCOSEの書き方を、避難所（指定避難所・小学校）の例で、日本語の義務文として示す。  
> 英語の `shall` は使わない。日本語では **「〜すること。」** を義務（shall）とする。

**結論・提言**

- 良い要求は、知らない第三者が訓練や点検で合否をつけられる一文である。
- 日本語では「快適に」「できるだけ」「必要に応じて」を書かず、数・時間・条件に落とす。
- 主語は滞在者ではなく、避難所またはそのサブシステムにする。
- 1文に義務は1つ。`および` で要求を繋げない。
- 根拠・仮定は本文に混ぜず、根拠欄に置く。

**対象読者への影響**: この例を型紙にして、自市町村の避難所要求を書き始められる。

## 1. 日本語の文型

義務は **「すること。」** で止める。推奨（should）は「することが望ましい。」、許可（may）は「することができる。」とし、要求セットには混ぜない。

| 型 | 文型 | いつ使うか |
|---|---|---|
| 常時 | `[主体]は、[対象]を[動作]すること。` | 開設中ずっと成り立つこと |
| 事象 | `[トリガ]したとき、[主体]は、[応答]すること。` | 開設宣言、受付完了など |
| 状態 | `[状態]の間、[主体]は、[応答]すること。` | 滞在期間中、断水中など |
| 異常 | `[条件]の場合、[主体]は、[応答]すること。` | 容器なし、負傷者ありなど |

**主語の置き方**

- よい: `避難所は、〜すること。` / `運営班は、〜すること。`
- わるい: `滞在者は、受付を済ませること。`（利用者への命令になっている）
- わるい: `受付が3時間以内に開始されること。`（誰がやるか不明）

**用語**は用語集で定義し、本文では同じ語だけを使う。本資料の定義は付録A。

## 2. 悪い文から良い文へ

| わるい（検証できない） | なぜだめか | よい（検証できる） |
|---|---|---|
| 避難所は快適でなければならない。 | 「快適」の合否が人による | 避難所は、開設を宣言したとき、滞在者1人あたり3.5平方メートル以上の居住スペースを確保すること。 |
| できるだけ早く受付を始める。 | 「できるだけ」は逃げ | 避難所は、開設決定から3時間以内に、滞在者の受付を開始すること。 |
| 必要に応じて福祉避難所へ conceierge する。 | 条件も期限もない | 運営班は、要配慮者スペースで対応できない滞在者について、識別から1時間以内に、福祉避難所への移送を市災害対策本部へ要請すること。 |
| 最新の避難所アプリを導入する。 | 実装（How）を先に固定している | 運営班は、開設から3時間以内に、滞在者数、負傷者の有無、およびインフラ状況を市災害対策本部へ報告すること。 |
| トイレを適切に確保する。 | 「適切」は主観 | 避難所は、滞在期間中、24時間利用可能な衛生設備を提供すること。 |
| 開設したらパーティションやベッドをなるべく出す。 | 時期と数量が曖昧 | 避難所は、開設を宣言したとき、使用中の各居住スペースに間仕切りと簡易ベッドを設置すること。 |

## 3. 良い要求の例

前提人数は説明用に **想定最大滞在者数200人** とする。実プロジェクトでは TBD を残し、指定状況調査で確定する。

### 3.1 機能・性能（居住・受付）

**REQ-LIV-001 居住面積**  
避難所は、開設を宣言したとき、滞在者1人あたり3.5平方メートル以上の居住スペースを確保すること。

- 根拠: 内閣府「避難生活における良好な生活環境の確保に向けた取組指針」（令和6年12月改定）のスフィア基準。
- 検証: 検査。使用中区画の実測値が3.5平方メートル以上。

**REQ-LIV-002 開設時の寝床**  
避難所は、開設を宣言したとき、使用中の各居住スペースに間仕切りを設置すること。

**REQ-LIV-003 開設時の簡易ベッド**  
避難所は、開設を宣言したとき、使用中の各居住スペースに簡易ベッドを設置すること。

- 根拠: 能登半島地震を踏まえた指針改定。開設翌日ではなく開設時点。
- 注: 間仕切りとベッドは別要求。片方だけ欠けても不合格にできるように分ける。

**REQ-RCV-001 受付開始**  
避難所は、開設決定から3時間以内に、滞在者の受付を開始すること。

**REQ-RCV-002 名簿記載**  
運営班は、受付した各滞在者について、氏名、年齢、性別、配慮事項、および受付時刻を名簿に記録すること。

- 注: 記載項目はデータ辞書で定義する。`および` は「1人の記録項目」であり、義務は「記録すること」の1つ。

**REQ-RCV-003 要配慮者の識別**  
運営班は、受付時に、特別な配慮を要する滞在者を識別すること。

**REQ-RCV-004 要配慮者の配置**  
運営班は、特別な配慮を要する滞在者を、要配慮者スペースへ割り当てること。

**REQ-RCV-005 福祉避難所への要請**  
運営班は、要配慮者スペースで対応できない滞在者について、識別から1時間以内に、福祉避難所への移送を市災害対策本部へ要請すること。

### 3.2 運用適合（情報・衛生・食事・水）

**REQ-INF-001 初回報告**  
運営班は、開設から3時間以内に、滞在者数、負傷者の有無、およびインフラ状況を市災害対策本部へ報告すること。

**REQ-INF-002 報告様式**  
運営班は、市災害対策本部への状況報告に、所定の報告様式 ICD-Shelter-EOC を用いること。

**REQ-INF-003 定期報告**  
運営班は、滞在期間中、4時間ごとに滞在者数と不足物資を市災害対策本部へ報告すること。

**REQ-SAN-001 衛生設備の可用性**  
避難所は、滞在期間中、24時間利用可能な衛生設備を提供すること。

**REQ-SAN-002 衛生設備の数量**  
避難所は、名簿登録された滞在者20人あたり1基以上の衛生設備を提供すること。

**REQ-WAT-001 72時間の飲料水**  
水供給班は、想定最大滞在者数に対し、1人1日3リットル以上、開設後72時間分の飲料水を現地に備蓄すること。

- 検証: 分析。200人 × 3リットル × 3日 = 1,800リットル以上が現地倉庫にあること。

**REQ-WAT-002 断水時の供給**  
上水道が使えない場合、水供給班は、備蓄飲料水により REQ-WAT-001 の供給量を維持すること。

**REQ-FOD-001 72時間の食事**  
食事班は、想定最大滞在者数に対し、1人1日3食、開設後72時間分の食事を現地備蓄で供給できること。

**REQ-FOD-002 食事の提供開始**  
食事班は、開設から6時間以内に、最初の食事提供を開始すること。

**REQ-FOD-003 アレルギー把握**  
食事班は、食物アレルギーの申告がある滞在者へ、申告内容と不一致のない食事を提供すること。

### 3.3 形態（施設）

**REQ-FAC-001 居住に使えない面積の除外**  
施設班は、居住スペースの面積算定から、階段、柱、固定棚、および運営・物資・通路に使う面積を除くこと。

**REQ-FAC-002 要配慮者スペースの位置**  
施設班は、要配慮者スペースを、多目的トイレから歩行距離30メートル以内に設けること。

**REQ-FAC-003 非常照明**  
施設班は、外部電源が途絶えたとき、受付、衛生設備、および主要な通路を、開設後12時間以上照明すること。

### 3.4 品質（安全性・運営体制）

**REQ-QLT-001 男女の運営責任者**  
運営班は、運営責任者として男性1名および女性1名を配置すること。

**REQ-QLT-002 女性用品のアクセス**  
運営班は、女性用衛生用品を、女性の運営責任者または女性の担当者が管理する場所に保管すること。

**REQ-QLT-003 巡回**  
運営班は、滞在期間中、2時間ごとに居住区画、衛生設備、および外部出入口を巡回すること。

**REQ-QLT-004 運用寿命ではなく開設継続**  
避難所は、市災害対策本部が閉鎖を指示するまで、REQ-SAN-001 および REQ-INF-003 を継続すること。

- 注: 「3年の運用寿命」は家電の例。避難所では閉鎖指示まで継続、と書く。

### 3.5 適合（法規・指針）

**REQ-CMP-001 指定基準**  
避難所は、災害対策基本法施行令第20条の6に定める指定避難所の基準に適合すること。

**REQ-CMP-002 個人情報**  
運営班は、滞在者名簿を、施錠できる場所に保管すること。

## 4. ニーズと要求を並べて見る

要求は、ニーズの主語を入れ替えた文ではない。システムが何をすれば期待を満たすかを、測れる義務に変える。

| ニーズ（外側の期待） | 要求（内側の義務） |
|---|---|
| 滞在者は、世帯単位の居住空間と簡易ベッドで休めることを必要とする。 | REQ-LIV-001 / 002 / 003 |
| 地域運営責任者は、職員到着前に事前レイアウトで開設を始められることを必要とする。 | 運営班は、開設判断のあと、市職員の到着を待たずに、事前レイアウト図に従って居住区画の設置を開始すること。 |
| 市災害対策本部は、開設後3時間以内に人数・負傷・インフラを把握できることを必要とする。 | REQ-INF-001 / 002 |
| 滞在者は、昼夜を問わず使える衛生的なトイレを必要とする。 | REQ-SAN-001 / 002 |
| 運営側は、受付時点で配慮が必要な人を識別し、適切な場所または福祉避難所につなげることを必要とする。 | REQ-RCV-003 / 004 / 005 |

## 5. 書いた日に付ける属性（例）

良い要求は文だけでは終わらない。次を同じ日に付ける。

| 要求ID | 区分 | 検証方法 | 成功基準 |
|---|---|---|---|
| REQ-LIV-001 | 機能・性能 | 検査（実測） | 使用中区画が1人あたり3.5平方メートル以上 |
| REQ-RCV-001 | 機能・性能 | デモ（開設訓練） | 開設決定時刻から180分以内に最初の受付 |
| REQ-INF-001 | 運用適合 | デモまたは実災害記録 | 開設時刻から180分以内の第一報 |
| REQ-WAT-001 | 運用適合 | 分析 | 現地在庫が1,800リットル以上 |
| REQ-FAC-003 | 形態 | 試験 | 外部電源遮断後12時間、指定箇所が照明されている |
| REQ-QLT-001 | 品質 | 検査 | 責任者名簿に男女各1名以上 |

## 6. 書き始め用のチェック（1件ごと）

次がすべて「はい」なら、その文は要求として使える。

1. 主語は避難所またはサブシステムか。滞在者への命令になっていないか。
2. 義務は「すること。」で終わっているか。
3. 曖昧語（適切、快適、できるだけ、必要に応じて、迅速に）がないか。
4. 数または時間または条件があるか。
5. 1文の義務は1つか。
6. どの部品・どのアプリを使え、と書いていないか。
7. 訓練または点検で合否をつけられるか。
8. 根拠は本文ではなく根拠欄にあるか。

## 付録A. 用語集

| 用語 | 定義 |
|---|---|
| 避難所 | 本資料では、市立A小学校の指定避難所システム（施設・備蓄・運営を含む） |
| 開設決定 | 市町村が当該施設を避難所として開設すると決めた時刻 |
| 開設を宣言したとき | 現地で避難所開設を掲示または放送した時点 |
| 滞在者 | 当該避難所の名簿に受付された人 |
| 想定最大滞在者数 | 居住スペース3.5平方メートル/人で算定した最大人数。本資料の例では200人 |
| 居住スペース | 滞在者が休む区画。通路、物資置場、受付、衛生設備を含まない |
| 間仕切り | 世帯または個人の視線を遮るパーティション |
| 簡易ベッド | 段ボールベッドまたは同等の床上寝具。床に直接敷く毛布だけの状態は含まない |
| 衛生設備 | 水洗トイレ、携帯トイレ、トイレカーなど、排泄に使う設備 |
| 運営班 | 開設後の現地運営を担う体制。市職員、施設管理者、地域運営責任者を含む |
| 市災害対策本部 | 当該市の災害対策本部 |
| 特別な配慮を要する滞在者 | 要介護高齢者、障がい者、医療的ケアが必要な者、妊産婦、乳幼児 |
| 要配慮者スペース | 一般居住区画とは分けた、当該避難所内の専用区画 |
| インフラ状況 | 電気、上水道、下水道、通信、ガスの使用可否 |
| ICD-Shelter-EOC | 避難所と市災害対策本部の間の報告様式 |
