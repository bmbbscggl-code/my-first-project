## 調査ブリーフ

### 背景事実

#### 1. CNNとは何か（定義）

- 畳み込みニューラルネットワーク（Convolutional Neural Network, CNN / ConvNet）は、画像・音声など空間的・局所的な構造を持つ入力向けのニューラルネットワークである。画像分類・物体認識で広く使われてきた。（出典: IBM “What are Convolutional Neural Networks?”）
- CNN以前は、画像から「特徴」を人手で設計して抽出していた。CNNは行列演算（局所的な積和）で画像内のパターンを自動的に見つける、よりスケーラブルな方法を提供する。学習には計算負荷が大きく、GPUが用いられることが多い。（出典: IBM）
- スタンフォード大学講義 CS231n の定義: CNNは通常のニューラルネットワークと同様、学習可能な重みとバイアスを持つニューロンからなり、入力ピクセルからクラス得点までの微分可能な関数を表現する。違いは「入力が画像である」という仮定をアーキテクチャに組み込み、全結合よりパラメータ数を大幅に減らす点にある。（出典: CS231n Convolutional Networks）
- CNNの典型的な3種の層: 畳み込み層（Convolutional）、プーリング層（Pooling / downsampling）、全結合層（Fully-connected）。最後の全結合層が分類を行うことが多い。（出典: IBM; CS231n）

#### 2. 畳み込み（convolution）とフィルタ（filter / kernel）

- カラー画像は高さ×幅×深さ（RGBの3チャネル）の3次元配列（ピクセルの行列）として扱われる。（出典: IBM; CS231n）
- フィルタ（カーネル、特徴検出器とも呼ばれる）は小さな重みの2次元配列。典型サイズは 3×3（IBM）。CS231n の初層例では 5×5×3（幅・高さ5、RGBの深さ3）。AlexNet 初層は 11×11×3。（出典: IBM; CS231n; Krizhevsky et al., 2012）
- 畳み込みの操作: フィルタを画像の局所領域（受容野 / receptive field）に当て、対応するピクセル値とフィルタ重みの内積（ドット積）を計算し、1つの数値を出力する。フィルタをストライド（stride）だけずらして画像全体を走査する。出力の2次元配列を特徴マップ（feature map / activation map / convolved feature）と呼ぶ。（出典: IBM; CS231n）
- パラメータ共有（parameter sharing）: 同じフィルタの重みは画像上のすべての位置で共通。ある位置で水平線を検出するのが有用なら、他の位置でも同じ検出器を使い回せる、という仮定に基づく。これによりパラメータ数が大幅に減る（例: 共有なしなら初層約1.06億パラメータ、共有ありなら約3.5万）。（出典: IBM; CS231n）
- ハイパーパラメータ: フィルタ数（出力の深さ）、ストライド（ずらすピクセル数）、ゼロパディング（端を0で埋めるか）。出力空間サイズの公式は `(W − F + 2P) / S + 1`。（出典: IBM; CS231n）
- 畳み込みのあと、非線形変換として ReLU（Rectified Linear Unit, `max(0, x)`）を適用するのが一般的（AlexNet以降）。（出典: IBM; Krizhevsky et al., 2012）
- 比喩「虫めがね」との対応（事実側）: 技術用語は「局所受容野を持つ小さなフィルタを画像上で滑らせる（slide / convolve）」である。フィルタは画像全体を一度に見るのではなく、小さな窓だけを見て、その窓に「線」「色の塊」など特定のパターンがあるかを数値で測る。同一フィルタを全位置で使い回す。（出典: CS231n “we slide (more precisely, convolve) each filter”; IBM “the filter shifts by a stride”）。「虫めがね」は教育用比喩であり、論文の用語ではない。

#### 3. プーリング（pooling）

- プーリングは空間方向のダウンサンプリング。フィルタに学習可能な重みはなく、窓内の値を集約する。（出典: IBM; CS231n）
- 主な種類:
  - 最大プーリング（max pooling）: 窓内の最大値を残す。より一般的。
  - 平均プーリング（average pooling）: 窓内の平均を取る。
- よく使われる設定: 2×2、ストライド2。CS231n によれば、これにより各深さスライスの空間サイズが半分になり、活性化の約75%が捨てられる。（出典: CS231n）
- 効果: パラメータ数と計算量の削減、過学習の抑制、小さな位置ずれへの鈍感さ（並進不変性の近似）。情報は失われる。（出典: IBM; CS231n; LeCun et al., 1998 の subsampling の説明）
- LeCun et al. (1998) の定式化: 特徴の「正確な位置」は識別に不要で、他の特徴との大まかな位置関係だけが重要。サブサンプリング（当時は局所平均）で特徴マップの解像度を下げ、位置の精密さを落とす。（出典: LeCun, Bottou, Bengio, Haffner, 1998）

#### 4. 層を重ねること（階層的特徴）

- 浅い層は単純な特徴（色、エッジ／線）、深い層はより大きな形・部分・物体を捉える、という階層が観察されている。（出典: IBM; Zeiler & Fergus, 2014）
- Zeiler & Fergus (ECCV 2014 / arXiv 2013) は deconvnet で各層の活性化を画素空間に戻し、次を報告した（ImageNet検証集合、AlexNet系モデル）:
  - Layer 2: 角、エッジと色の結合
  - Layer 3: より複雑な不変性。似たテクスチャ（網目、文字など）
  - Layer 4: クラス特有の部分（犬の顔、鳥の脚など）
  - Layer 5: 姿勢の異なる物体全体（キーボード、犬など）
- IBM の自転車の例: フレーム・ハンドル・車輪などの低レベルパターンが組み合わさり、高レベルパターン（自転車）になる。
- CS231n: 初層フィルタは向きのあるエッジや色のしみ、より上層ではハニカムや車輪のようなパターンに反応するフィルタを学習する、と直感的に説明している。
- 注意: 「線→形→物体」は可視化研究で支持される経験的観察であり、すべての層・すべてのモデルで厳密にこの順になるわけではない。Layer 5 が背景の草に反応する例も同論文にある（前景物体ではなく背景に注目する特徴マップ）。

#### 5. 学習（教師あり学習・誤差逆伝播）

- CNNの畳み込み層・全結合層の重みは、訓練集合のラベルと予測が一致するよう勾配降下法で更新される。ReLU・プーリング層には学習パラメータがない。（出典: CS231n）
- 学習の流れ（事実）: 入力画像 → 順伝播でクラス得点（よく Softmax で0〜1の確率）→ 正解ラベルとの損失（loss）→ 誤差逆伝播（backpropagation）で勾配を計算 → 重みを少し更新。これを多数の画像で繰り返す。（出典: CS231n; LeCun et al., 1998 の gradient-based learning）
- フィルタの中身は最初から「ネコ用」と決まっているのではなく、大量の正解付き画像を見て自動的に決まる。（出典: IBM “weights … adjust during training through … backpropagation and gradient descent”; CS231n）
- 全結合層は抽出済み特徴を用いて分類する。出力はクラスごとの得点／確率。（出典: IBM）
- ゼロからの大規模学習には大量のラベル付き画像が必要（後述 ImageNet 約128万枚）。一方、既に学習済みの特徴抽出器（例: MobileNet）の上に分類器だけを付け替える転移学習では、クラスあたり数十枚規模でもデモ可能な場合がある（後述 Teachable Machine）。枚数目安は課題・手法で大きく異なる。単一の「何枚あれば十分」という公式値は存在しない。

#### 6. デジタル画像とピクセル（比喩の根拠）

- カラーデジタル画像は画素（ピクセル）の2次元配列であり、各画素は赤・緑・青（RGB）の3チャネルの強度で表される。（出典: Wikipedia “Channel (digital image)”; Scratchapixel）
- 一般的な 8 bit/チャネルでは、各チャネルは整数 0〜255（0が最小、255が最大）。3チャネル合わせて約 256³ = 16,777,216 色。（出典: Wikipedia Channel; Scratchapixel; Photography Life の解説）
- CNNはこの数値の格子を入力とし、「目」や「光」を持たない。計算は数値の積和である。（出典: CS231n “from the raw image pixels … to class scores”; Esteva et al., 2017 “using only pixels and disease labels as inputs”）
- 代表的な入力サイズの例:
  - MNIST: 28×28 グレースケール（1チャネル）。（出典: LeCun MNIST 公式ページ）
  - CIFAR-10: 32×32×3。（出典: Krizhevsky CIFAR 公式ページ）
  - 多くのImageNet用CNN: 224×224×3（AlexNet論文の記載。CS231n は実装上 227×227 が整合すると注記）。（出典: Krizhevsky et al., 2012; CS231n）

#### 7. 歴史の要点

- 1979年（日本語論文）／1980年（英語）: 福島邦彦がネオコグニトロンを発表。哺乳類視覚皮質（Hubel & Wiesel の単純細胞・複雑細胞）に着想した階層モデル。S細胞（特徴抽出）とC細胞（位置ずれへの鈍感さ／プーリングに相当）を交互に重ねる。教師なし自己組織化。位置ずれに強いパターン認識を目指した。現代CNNの先駆とされることが多い。（出典: Fukushima, Biological Cybernetics, 1980; 電子情報通信学会論文誌 1979; IBM も1980年の福島を基盤として言及）
- 1989年: Yann LeCun らが誤差逆伝播で畳み込みネットを訓練し、米国郵便公社の手書き郵便番号数字認識に適用（LeNet-1 の原型）。（出典: LeCun et al., Neural Computation, 1989 “Backpropagation Applied to Handwritten Zip Code Recognition”; IBM）
- 1998年: LeCun, Bottou, Bengio, Haffner が LeNet-5 を含むサーベイ “Gradient-Based Learning Applied to Document Recognition” を発表。7層（入力除く）、入力 32×32。MNIST でテスト誤り率 0.95%（歪み拡張時 0.8%、Boosted LeNet-4 は 0.7%）。小切手認識など商用利用（NCR）。（出典: LeCun et al., Proc. IEEE, 1998）
- 2012年: Krizhevsky, Sutskever, Hinton の AlexNet（8学習層: 畳み込み5＋全結合3、約6000万パラメータ）が ILSVRC-2012 で top-5 テスト誤り率 15.3%（5モデル平均）。2位は 26.2%。2基の NVIDIA GTX 580 で約5〜6日学習。ReLU、Dropout、GPU実装が鍵。（出典: Krizhevsky, Sutskever, Hinton, 2012）
- 2014年: VGG（非常に深い 3×3 畳み込みの積み重ね）アンサンブル top-5 テスト誤り 6.8%。GoogLeNet（Inception） 6.7%。（出典: Simonyan & Zisserman, 2015; Russakovsky et al., 2015）
- 2015年: He らの ResNet（残差学習）。152層。アンサンブルの ImageNet テスト top-5 誤り 3.57% で ILSVRC 2015 優勝。単一 ResNet-152 の validation top-5 は 4.49%（論文 Table 4）。（出典: He, Zhang, Ren, Sun, CVPR 2016）
- 2015年頃: 熟練アノテータの人間 top-5 誤りは約 5.1%（1500枚サンプル）。GoogLeNet は同サンプルで 6.8%。（出典: Russakovsky et al., IJCV 2015; Karpathy, 2014）
- 2020年代: ImageNet の最高精度は Vision Transformer や画像−テキスト基盤モデル（例: CoCa, 2022, ファインチューン top-1 91.0%）など、純粋な古典的CNN以外の手法が上位に来る。CNNは今も広く使われるが、「画像認識＝CNNだけ」ではない。（出典: Yu et al., CoCa, 2022）。**注意: CoCa はCNNではなく、現行SOTAの帰属は要確認。**

#### 8. よくある誤解に対する事実

- 「AIは目で見ている」: 入力は画素の数値配列。カメラやセンサが光を数値化したあと、積和と非線形変換だけが行われる。「見る」「理解する」は比喩。（出典: CS231n; Esteva et al., 2017）
- 「1枚見れば完璧」: 大規模分類の標準的学習は数十万〜百万枚規模。転移学習でもクラスあたり数十枚以上が実務・教材の目安として語られる。1枚では一般化しないのが原則。例外的な few-shot 手法はあるが、小学生向け「いつも1枚で十分」は事実に反する。
- 「常に正しい」: ベンチマークでも誤り率はゼロではない。照明・ぼけ・ノイズ・角度で人間より大きく落ちることがある。人間にはほとんど分からない摂動で高自信に誤分類する（敵対的事例）。学習データの偏りで属性によって誤り率が大きく違う場合がある。

#### 9. 失敗例・限界

- 敵対的事例（adversarial examples）: 人間にはほとんど分からない摂動で、高精度モデルの予測を任意に変えられる（Szegedy et al., arXiv 2013/ICLR 2014）。Goodfellow et al. (2014/2015) の有名な図: GoogLeNet がパンダ（信頼度 57.7%）を、ε=0.007 の摂動でテナガザル（99.3%）と判定。ε=0.007 は 8bit 画像の最小ビット相当、と論文は述べる。
- 照明・ぼけ・ノイズ: Dodge & Karam (2017) は、きれいな画像ではDNNと人間が同程度でも、ぼけ・ノイズでは人間の方が大幅に高い、と報告。ImageNet-C（Hendrycks & Dietterich, 2019）は明るさ・コントラスト・霧・ぼけ・ノイズなど75種の腐敗で頑健性を測る。
- 角度・視点: 視点変化で誤分類しやすく、人間の視点不変性には及ばない、という評価研究がある（例: ViewFool, NeurIPS 2022）。**個々の誤分類率の単一公式値は課題依存。**
- バイアス: Buolamwini & Gebru, Gender Shades (2018)。商用性別分類3システムで、明るい肌の男性の誤り率は最大 0.8%、暗い肌の女性は最大 34.7%（最も暗い Fitzpatrick VI では約46%という記述も MIT News にある）。顔分析ベンチマーク自体が明るい肌に偏っていた（IJB-A 79.6%、Adience 86.2% が明るい肌）。
- Face ID の公式限界: 他人がロック解除できる確率は約100万分の1とAppleは述べるが、一卵性双生児・よく似た兄弟姉妹・13歳未満（顔の特徴が未発達）では誤一致確率が上がる、と公式に注記。（出典: Apple Face ID Security / Support）
- 医療AI: 日本の薬事承認製品でも「医師の補助」であり、装置単独での確定診断を目的としない、と添付文書に明記される例がある（EndoBRAIN-EYE）。

### 根拠データ

歴史的ベンチマークの数値は発表年が3年以上前（2023-09以前）のものが大半である。数値自体は一次論文で安定しているが、**現行製品の精度をこれらで代用してはならない。**

- データ1: ILSVRC-2012（通称 ImageNet-1K）は訓練 1,281,167 枚、検証 50,000 枚、テスト 100,000 枚、1000クラス。（出典: Hugging Face ILSVRC/imagenet-1k; UCI ImageNet ページ。AlexNet論文は「およそ120万／5万／15万」と概数表記）
- データ2: ImageNet 全体（2014年8月時点）は 21,841 synset、注釈付き画像 14,197,122 枚、1 synset あたり平均約650枚。（出典: Russakovsky et al., IJCV 2015; image-net.org about-stats, 2010-04-30 更新のアーカイブ）
- データ3: AlexNet（2012）ILSVRC-2012 top-5 テスト誤り 15.3%（5CNN平均）。単体は 18.2%。2位エントリ 26.2%。ILSVRC-2010 では top-1 37.5% / top-5 17.0%。パラメータ約6000万、学習は2 GPUで約90エポック・5〜6日。（出典: Krizhevsky et al., 2012）**2012年の結果。**
- データ4: ILSVRC 分類誤りは、提供訓練データのみの比較で 2010年頃 28.2% → 2014年 6.7%（約4.2倍改善）。2012年以降同一データで 16.4% → 6.7%（約2.4倍）。（出典: Russakovsky et al., 2015）**2015年論文。**
- データ5: 人間（熟練アノテータA1）の ImageNet top-5 誤り 5.1%（1500枚）。同サンプルの GoogLeNet 6.8%。Karpathy 個人も 5.1%。初心者5人は 74〜89%（中央値81%）という別計測もある。（出典: Russakovsky et al., 2015; Karpathy, 2014; AI Impacts Wiki がこれを整理）**2014–2015年。初心者数値は少人数。**
- データ6: ResNet アンサンブル ILSVRC 2015 テスト top-5 誤り 3.57%。単一 ResNet-152 の validation top-5 4.49% / top-1 21.43%（10-crop 等の条件は論文参照）。（出典: He et al., 2016）**2015–2016年。人間5.1%より低いが、課題・評価手続きが同一ではない点に注意。**
- データ7: CoCa（画像−テキスト基盤モデル、CNNではない）の ImageNet top-1: zero-shot 86.3%、凍結エンコーダ 90.6%、ファインチューン 91.0%。（出典: Yu et al., 2022）**2022年。3年以上前。現行リーダーボードの首位は二次集計が多く要確認。**
- データ8: MNIST は訓練 60,000、テスト 10,000、28×28 グレースケール、10クラス（手書き数字）。（出典: yann.lecun.com/exdb/mnist）
- データ9: LeNet-5 の MNIST テスト誤り 0.95%（通常）、歪み拡張時 0.8%。訓練19パス後の訓練誤り 0.35%。学習時間は当時 SGI Origin 2000（200 MHz R10000 1基）で2〜3日。（出典: LeCun et al., 1998）**1998年。**
- データ10: CIFAR-10 は 60,000 枚の 32×32 カラー、10クラス、クラスあたり 6,000 枚。訓練 50,000 / テスト 10,000。クラス: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck。（出典: cs.utoronto.ca/~kriz/cifar.html, Krizhevsky 2009）
- データ11: CIFAR-100 は100クラス、クラスあたり600枚（訓練500＋テスト100）。（出典: 同上）
- データ12: GTSRB（ドイツ交通標識）は43クラス、論文記載で 51,840 枚。公式サイトは「40クラス超、合計5万枚超」。よく使われる分割は訓練 39,209 / テスト 12,630。（出典: Stallkamp et al., Neural Networks 2012; Stallkamp et al., IJCNN 2011; benchmark.ini.rub.de）照明・天候・隠れ・回転のばらつきを含む。
- データ13: GTSRB で CNN委員会 99.46%、人間最良個人 99.22%、人間平均 98.84%。CNN委員会が最良人間を有意に上回った（McNemar p=0.01366）。小さい画像ほど誤りが増える。（出典: Stallkamp et al., 2012）**2011–2012年の切り抜き画像分類。実車の検出＋追跡とは別。**
- データ14: Esteva et al., Nature 2017。皮膚病変 CNN（Inception v3、ImageNet約128万枚で事前学習＋転移学習）。データ 129,450 枚（うちダーモスコピー 3,374）、疾患概念 2,032。訓練・検証 127,463、生検ラベル付きテスト 1,942。21人の専門医と比較し、主要な2値分類（癌 vs 良性）で専門医水準。（出典: Esteva et al., 2017）**研究性能であり、病院導入の保証ではない。2017年。**
- データ15: 医療画像DLの系統的レビュー（Medline/EMBASE〜2020年1月、503研究）。眼科AUC 0.933〜1、呼吸器 0.864〜0.937、乳腺 0.868〜0.909。研究間の異質性が高く、精度の過大評価の可能性を著者らが指摘。（出典: Aggarwal et al., PMC8027892, 2021）**3年以上前。**
- データ16: オリンパス「EndoBRAIN」（2019年国内発売、内視鏡分野で国内初の薬事承認と発表）。約60,000枚の内視鏡画像を学習。国内多施設後ろ向き試験で感度 96.9%、正診率 98.0%。（出典: オリンパス 2019-03-08 ニュースリリース）**製造販売承認はサイバネットが2018-12-06取得、とリリース記載。**
- データ17: Apple Face ID。TrueDepth が約30,000個の赤外線ドットで深度マップ＋2D赤外画像を取得。Secure Enclave 内のニューラルネットワークで照合。他人の顔で解除できる確率は約 1/1,000,000（Touch ID は 1/50,000）。5回失敗でパスコード必須。データは端末外に出さない、と公式。（出典: Apple Face ID Security Guide; Apple Support）**3D深度＋専用NNであり、2D写真を普通のCNNで分類する方式とは異なる。**
- データ18: Google の写真検索（2013年ブログ）。ILSVRC優勝チームに近いCNNを大規模学習。初期ラベル約2000 → 精度の高い1100クラスでローンチ。クラスあたり訓練画像は ImageNet の約1000枚に対し約5000枚を使用、と記載。（出典: Rosenberg, Google Research Blog, 2013-06-12）**2013年の当時のシステム。現行 Google Photos のモデルは非公開・要確認。**
- データ19: Gender Shades（2018）。暗い肌の女性の性別分類誤り最大 34.7%、明るい肌の男性は最大 0.8%。（出典: Buolamwini & Gebru, 2018; MIT News 2018-02-12）
- データ20: 敵対的事例のパンダ図。信頼度 57.7%（panda）→ 99.3%（gibbon）、ε=0.007。（出典: Goodfellow, Shlens, Szegedy, 2014/2015）
- データ21: 小池誠（静岡県湖西市、キュウリ農家）の選別AI。9等級×275枚＝合計 2,475 枚で試作1号機、正答率約8割、と本人談の取材記事。TensorFlow のCNN。コストはウェブカメラ等で約3000円、という記述あり。（出典: マイナビ農業 2019-10-01; ITmedia 2018-03-12）**取材記事。査読論文ではない。枚数は後の機種で「約1万枚」という別記述もあり、時点で値が違う。要確認。**
- データ22: 日本の郵便番号自動読取区分機（東芝 TR-3/TR-4、1968年7月1日東京中央郵便局で公開）。自由手書き数字のOCRとして世界初の実用化、と情報処理学会コンピュータ博物館。手書きサンプル約30万字。処理 20,000通/時、3桁。**これは古典的OCRでありCNNではない。** 学習データ量の歴史例、および小学校「みらプロ」の題材として使える。（出典: 情報処理学会コンピュータ博物館; 郵政博物館）
- データ23: Teachable Machine 系の転移学習教材。Google Codelabs（TensorFlow.js）はデモで「各クラス少なくとも30サンプル」と案内。Coral 公式は MobileNet（1000物体で事前学習したCNN）の埋め込みを使い、少数例で新クラスを教える、と説明。クラスあたり50〜200枚という数値は非公式ブログが多く、**公式の一律推奨枚数は確認できず要確認。**
- データ24: CS231n の規模感の例。CIFAR-10 の 32×32×3 を全結合すると1ニューロンあたり 3,072 重み。200×200×3 なら 120,000 重み。CNNは局所接続でこれを避ける。

### 参考事例

- 事例1: Google 写真検索（2013〜） — ILSVRC 2012 系のCNNを個人写真検索に適用。手動タグなしで「花」「食事」「車」等を検索。Web画像で学習してもスナップ写真に汎化した、と当時のブログ。誤りは「バナナナメクジをヘビと誤る」など、人間にも尤もな混同が多い、と記載。 — 結果: 2013年に Google+ Photos / 後の Google Photos として一般提供。現行アーキテクチャは非公開。
- 事例2: Apple Face ID（2017〜） — 3D赤外深度＋ニューラルネットワーク照合。公式FMR 約100万分の1。写真やマスクによるなりすまし対策用の別NNを持つ。子ども・双生児では誤一致リスクが上がると公式注記。 — 結果: スマートフォンの顔認証の代表例。ただし「写真をCNNで分類」の単純モデルではない。
- 事例3: GTSRB / 運転支援の標識認識（2011〜） — 43種のドイツ標識、5万枚超。CNN委員会が 99.46% で人間最良（99.22%）を上回った。市販車のADASでも標識認識は研究・製品化されている（Stallkamp らも「既に一部車両で商用」と2012年時点で記載）。 — 結果: 「標識は色と形がはっきりしている課題では機械が非常に高い」一方、実世界は照明・天候・隠れで難しくなる、という対比に使える。日本の実車精度の公式包括値は未確認。
- 事例4: Esteva et al. 皮膚がん分類（2017） — 約13万枚でCNNを訓練し、21人の皮膚科専門医と画像のみの比較で同水準。 — 結果: 「病院の画像診断」の学術的里程碑。臨床導入・日本の薬事とは別。
- 事例5: オリンパス EndoBRAIN / EndoBRAIN-EYE（2018承認・2019発売〜） — 大腸の超拡大／通常内視鏡画像をAI解析。約6万枚学習、感度96.9%・正診率98.0%（後ろ向き試験）。位置づけは医師の補助。 — 結果: 日本の子どもが「病院の機械がポリープを見つける手伝いをする」と説明する実在製品。
- 事例6: 富士フイルム CAD EYE（EW10-EC02 大腸 2020、EW10-EG01 上部消化管 2022 薬事承認） — ディープラーニングで病変をリアルタイム検出・枠表示・音で通知。拡張ユニット EX-1 の国内累計導入 1000台突破、と2024年時点のリリース。 — 結果: 日本企業の医療画像AIの身近な例。ネットワークがCNNであることの製品公式明記は、公開ページ上では「ディープラーニング」が主。**CNN特定は要確認。**
- 事例7: 印西市立原山小学校（2023〜、みんなのコード連携） — Teachable Machine でジャンケンの手や国旗を学習。背景や写り込みで結果が変わることに児童が気づく。Stretch3（Scratch拡張）と組み合わせて身の回りの問題解決。 — 結果: 日本の小学校で再現可能な体験。主要メッセージ（データ・特徴・条件で間違える）と直結。
- 事例8: 文部科学省「みらプロ」Google案件 — Teachable Machine（2020年7月日本語化）＋ TM2Scratch。画像・音声認識AIを自分で作り Scratch で使う。指導案に「きゅうり農家」「クリーニング」事例、Google Cloud Vision で教室の物を撮って名前を当てる体験が含まれる。（出典: mext.go.jp/mirapro; 令和元年度指導案集PDF）
- 事例9: 宮城教育大学附属小学校「小学校情報科」研究開発（2023年度〜、文科省研究開発学校） — 6年で Teachable Machine＋Scratch により機械学習と学習データの存在を体験。
- 事例10: 小池誠のキュウリ選別AI（静岡、2016〜） — 母親の9等級選別をCNNで再現。数千枚規模で正答率約8割の試作。教育現場で「身近な仕事の画像認識」として引用されやすい（みらプロ指導案の「きゅうり農家」と符合）。
- 事例11: 日本の郵便番号OCR（1968〜） — CNNではないが、「機械が数字の絵を読んで仕分ける」日本独自の生活インフラ。みらプロ「日本郵便」教材で小学校3年社会＋プログラミングと結びつく。手書きサンプル約30万字。
- 事例12: JR東日本 顔認証改札の実証（2025年秋、新潟駅・長岡駅の上越新幹線） — 定期券利用者向け。パナソニックコネクトとNECが各駅の技術を担当。目的は精度、照度・カメラ角度・温湿度、歩行速度と距離の確認。マスクやうつむきで特徴が少ないとNG、と報道。首都圏ラッシュでは顔認証では処理しきれないと判断し、UWBを本命とする、と2026年の公開資料・報道。 — 結果: 「駅の顔認証」は実証段階。子ども向けに「もう全国の改札が顔だけ」とは言えない。
- 事例13: Google Teachable Machine ＋ Coral / TensorFlow.js — 事前学習済み MobileNet（CNN）の特徴を使い、ウェブカメラの少数例で新クラスを学習。教材として「少ない枚数でも転移学習なら動く／条件が変わると失敗する」を示す公式に近いソース。

### 注意事項・情報の限界

- 本ブリーフの中核数値（AlexNet 2012、人間 5.1%、ResNet 3.57%、LeNet 0.95%、Gender Shades 2018、Esteva 2017、GTSRB 2012、Google Photos ブログ 2013、小池事例 2018–2019）はいずれも調査日（2026-09-02）から見て3年以上前である。歴史・仕組みの説明には使えるが、現行スマホ・車・病院製品の精度として提示してはならない。
- 「ImageNetで人間を超えた」は、top-5・特定の熟練アノテータ・2015年前後の比較に限定される。初心者人間はもっと誤りが多い。クラスが細かく（犬種など）、人間にも難しい課題である（Karpathy 2014 が指摘）。
- 現行 ImageNet top-1 首位（90%台）は Transformer / マルチモーダルモデルが中心。二次リーダーボード（CodeSOTA 等）の 2025–2026 年スコアは検証が不十分で要確認。CNN単体の最新SOTAは本調査では確定しなかった。
- Face ID・駅改札の顔認証は、教材の「2D写真＋畳み込み」モデルと実装が異なる。混同すると不正確になる。
- 医療AIの高精度は特定試験条件。医師の補助であり、単独診断装置ではない（日本の承認文書）。系統的レビューは手法のばらつきと過大評価リスクを警告（2021）。
- 自動運転の「標識認識」は、切り抜き分類ベンチマーク（GTSRB）と、検出・追跡・日本の標識・実車安全基準が別物。日本国内の量産車の標識認識精度の包括公式値は未確認。
- Teachable Machine の「何枚必要か」に公式の単一数字は見当たらなかった。Codelabs の「30枚」はデモ最小。50〜200枚は非公式ガイド。
- 小池キュウリの枚数・正答率は取材記事依存。2,475枚／約80%と「約1万枚」が混在。要確認。
- 郵便番号区分機（1968）はCNNではない。歴史的「絵（数字）を読む機械」としては有効、技術的にはOCR。
- 「虫めがね」は教育比喩。論文用語は filter / kernel / receptive field / sliding。
- 層の「線→形→物体」は Zeiler & Fergus の可視化に基づく典型ストーリー。すべての特徴マップが物体を見るわけではない。
- 敵対的事例のデモは研究用の最悪ケース摂動であり、日常写真がいつもそう壊れるわけではない。ただし「見た目が同じでも機械は別物と判断しうる」は事実。
- ImageNet には人物カテゴリの公平性・攻撃的語彙の問題が後年指摘され、2019・2021年に更新方針が発表されている（UCI / image-net.org）。子ども向けにデータセットを「中立な正解の山」と書くと不正確。

### 追加調査推奨項目

- 現行（2024–2026）の小学校1人1台端末で動く、日本向け画像認識教材の最新推奨手順（Teachable Machine の提供継続状況、代替ツール）。
- 日本の学習指導要領・教科書（2020年度以降の算数・理科・総合・技術）における「画像認識／AI」の公式記述の引用可能な箇所。
