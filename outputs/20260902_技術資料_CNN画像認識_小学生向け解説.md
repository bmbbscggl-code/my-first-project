## 1. はじめに：3分でわかるまとめ

**いちばん大事なこと：CNN（シーエヌエヌ。畳み込みニューラルネットワークの略）は、小さな「虫眼鏡（フィルタ。絵の一部分を調べる計算の道具）」で絵の特徴を何度も探し、だんだん「これは猫だ」と決める仕組みです。**

コンピュータは昔、絵を見て「猫か犬か」を決めるのがとても苦手でした。人間なら一瞬で分かることが、機械には難しかったのです。その課題に強く効いたアイデアが CNN です。

CNN は、絵をたくさんの小さなマス目に分け、虫眼鏡のような道具でなぞるように調べます。最初は「線があるか」「色の境目はどこか」などを調べ、あとから「耳の形」「ひげ」「目」といった複雑な形を見つけ、最後に「猫かも 90%」のように点数を出します（**この 90% は説明のための仮の数字です。本物の正解率ではありません**）。コンピュータが出す数字は、「どれくらいそう思っているか」の点数を 0〜100 に直したもので、かならず正しいわけではありません。

### 結論・提言（ここだけ読んでも要点が分かります）

- **CNN は「絵を読む機械の目」に近い仕組みです。** 小さな虫眼鏡（フィルタ）を絵の上でずらしながら、特徴を探します。
- **手前の層（そう。処理の段階）では線や色、奥の層ではより複雑な形を探しやすい、という性質があります。** ただし「層をたくさん重ねるほど必ず賢くなる」わけではありません。重ねすぎると逆に学びにくくなることもあり、その工夫も研究されています。
- **1998年の LeNet-5（レネット・ファイブ）は、手書き数字の読み間違いを約 0.95% まで減らした、当時の大事な記録です**（LeCun et al., 1998）。今は別の手法も含めて、さらに上手なやり方が増えています。
- **写真アプリや医療の手伝いなど、身近な場面で「画像を読む AI」が使われています。** 製品の中身が必ず CNN とは限りません。
- **CNN にも苦手なことがあります。** データの偏り、まちがい、プライバシー（個人の情報を守ること）を知ったうえで使うことが大切です。

**読んだあとにしてほしいこと**: 「機械の答えは便利だけれど、最後は人が確かめる」という考え方を、写真アプリや授業の実験で思い出してください。

## 2. なぜ「絵を読む機械」が必要なの？

**絵を自動で読める機械があると、人の仕事を助け、生活をより安全・便利にできるからです。**

みなさんは写真を見て「これは犬！」「あれはリンゴ！」とすぐ分かります。でもコンピュータにとって、絵は最初から「犬」ではありません。画面の色は、ぜんぶ数字で表されています。たとえば真っ赤は「赤 255・緑 0・青 0」、真っ黒は「赤 0・緑 0・青 0」のように、赤・緑・青の明るさを 0〜255 の数字で並べたものです。「この数字の並びは猫だ」と機械が決めるのは、長いあいだとても難しい問題でした。

### 2.1 背景

人が全部の写真にラベル（名前の札）を付けるのは時間がかかります。お医者さんが見る体の写真、道路の標識、学校のプリントの整理など、「絵を読む仕事」は世の中にたくさんあります。そこで、機械が絵の特徴を自分で学べる仕組みが求められました。

人間の目と脳も、いきなり「猫だ」と決めているわけではありません。まず線や向きを感じ、だんだん形を組み立てます。1962年、Hubel（ヒューベル）と Wiesel（ウィーゼル）はネコの脳の視覚の細胞が、特定の向きの線によく反応することを報告しました（Hubel & Wiesel, 1962）。1980年には福島邦彦（ふくしまくにひこ）さんが、そのヒントを受けた「ネオコグニトロン」という仕組みを発表しました（Fukushima, 1980）。**CNN は脳のコピーではありません。** 生き物の目の研究からヒントをもらった、人間が作った計算の発明です。

### 2.2 課題・問題点

| 課題 | いま困ること | 目指すこと | すき間 |
|---|---|---|---|
| 見え方が変わる | 丸まった猫も立った猫も「猫」と書き分けたい | 向きや形が少し違っても同じ仲間と答えられる | ルールを人が全部書くのは無理に近い |
| 光で色が変わる | 日かげの犬と日なたの犬 | 明るさが違っても同じ「犬」 | 色の数字だけ比べると失敗しやすい |
| かくれていても知りたい | 木の後ろのリンゴ | 一部が見えなくても見当をつけられる | 欠けた絵のルールも数えきれない |
| 量が多すぎる | 写真が何万枚もある | 人が全部見なくても下調べできる | 人手だけでは追いつかない |

昔のやり方は、「ここに黒い点が3つ並んだら数字の1」のように、人がルールを書くことでした。例外が多すぎて、猫や標識には向きませんでした。CNN は「たくさんの正解つきの絵を見せて、探す道具の数字を少しずつ直す」ことで、このすき間を埋めようとします。

### 2.3 スコープ（この資料の範囲）

**対象範囲**

- CNN が画像認識で何をしているかの全体像
- 虫眼鏡（フィルタ）・まとめ作業（プーリング）・最後の答え方の役割
- 家庭や授業でできる小さな実験
- まちがいやすさ・プライバシーなど、気をつけること

**対象外**

- プログラムの書き方そのもの（Python のコードは出しません）
- 最新の大会でいちばん高い点数（この資料の数字は主に歴史の記録です）
- 機械をだます細かい方法（安全のため書きません）
- ある会社のアプリの中身が CNN かどうかの断定

## 3. CNNってどんな仕組み？

**CNN は「虫眼鏡で絵をなぞる → 大事なところだけ残す → 何段か繰り返す → まとめて答える」という流れです。**

これはたとえ話です。本物のコンピュータの中では、虫眼鏡もインクもなく、数字のかけ算と足し算がたくさん行われています。

### 3.1 全体の流れ

```
【入力】 絵（色の数字の集まり）
    ↓
【畳み込み層】 小さな虫眼鏡（フィルタ）で特徴を探す
    ↓
【プーリング層】 いちばん強い反応など、大事な数字だけ残して小さくする
    ↓
     （この2つを何回か繰り返す）
    ↓
【全結合層】 集めた特徴を並べて、総合的に考える
    ↓
【出力】 「猫かも／犬かも」の点数を、足すと100になる数字に直す（真の確率ではない）
```

### 3.2 主要コンポーネント（部品の役割）

| 部品 | たとえ | 本当にやっていること |
|---|---|---|
| 畳み込み（たたみこみ） | 小さな虫眼鏡を絵の上でずらす | 小さな数字の表（フィルタ）を絵に重ね、かけ算と足し算で反応を出す |
| フィルタ（カーネル） | はんこ・スタンプ | 同じ形の道具を画像全体で使い回す（重みの共有） |
| 特徴マップ | 虫眼鏡が見つけたメモの地図 | 1つのフィルタが作る、反応の強さの表 |
| プーリング | 虫取り網でいちばん強い反応をすくう | 近くの数字を最大値や平均でまとめて、地図を小さくする |
| 全結合層 | メモを全部見て判定席に座る | 平らに並べた特徴を、すべてのマスとつなげる計算 |
| ソフトマックス | 点数をパーセントっぽく直す | 点数を 0 以上にして合計を 1（100%）にする。**本当の確率（さいころの正しさ）そのものではない** |

### 3.3 アーキテクチャ（組み立て）の概要

最初の畳み込みは、縦線・横線・色の境目のような単純なパターンに反応しやすいことが多いです。あとの段では、前の段のメモをさらに虫眼鏡で見るので、耳や車輪のような「部品」に反応しやすくなります。最後の判定席が、「猫」「犬」「車」などのクラス（種類）に点数を付けます。

ソフトマックスのあとの「猫 70%、犬 20%、うさぎ 10%」は、「機械がそう思っている度合い」の表し方です。70% だから本当に 10回中7回正しい、とは限りません。大事な判断では、人が絵を見て確かめます。

## 4. 虫眼鏡の仕組みを少し詳しく

**CNN の強みは、同じ小さな道具を絵のあちこちに使い、段を重ねて「線 → 部品 → 種類」と組み立てやすいことです。**

### 4.1 フィルタは何を探しているか

探偵チームが分担するイメージです。ある虫眼鏡は「縦の線」、別の虫眼鏡は「丸い形」を探します。フィルタは最初、でたらめに近い数字から始まります。たくさんの正解つきの絵で練習すると、役に立つ探し方が残ります。この直しかたを学習（がくしゅう）と呼び、フィルタの中の数字を重み（おもみ）といいます。

答えがはずれたとき、ずれを小さくするように重みを少しずつ直します。この直しかたの代表が誤差逆伝播（ごさぎゃくでんぱ。ずれを後ろから前へ伝えながら直す計算）です。「逆向き」なのは、最後の答えのまちがいから、どの虫眼鏡がどれくらい関係したかを逆にたどるからです。

### 4.2 浅い層と深い層

| 層の位置 | 探しやすいものの例 |
|---|---|
| 浅い層（入り口に近い） | 縦線・横線・色の変わり目 |
| 中くらい | しま模様、ざらざら、小さな形の組み合わせ |
| 深い層（出口に近い） | 目・耳・窓・タイヤなど、物の部品に近いパターン |
| いちばん最後 | 「猫」「犬」「自動車」などの種類の点数 |

**層を増やせば必ず賢くなる、わけではありません。** 深くしすぎると、練習がうまく進まなくなることがあります。2015年ごろの ResNet（レズネット。残差ネットワーク）は、「一段飛ばしの近道」を足すことで、とても深い網でも学びやすくした研究です（He et al., 2015/2016）。この資料では「段を重ねると、単純な特徴から複雑な特徴へ進みやすい。ただし重ね方の工夫も必要」と覚えてください。

### 4.3 歴史の数字（当時の記録）

| できごと | 内容 | 出典 |
|---|---|---|
| 1998年 LeNet-5 | 手書き数字 MNIST（エムニスト。0〜9の字の問題集）でテスト誤差 約0.95%。学ぶ数字（パラメータ）は約6万個 | LeCun et al., 1998 |
| 2012年 AlexNet | 大きな画像コンテスト ILSVRC（イメージネットを使った大会）で、上位5個の答えに正解が入らない割合（top-5誤差）が 15.3%。2位は 26.2%。パラメータは約6000万個 | Krizhevsky et al., 2012 |
| 2015年 ResNet | 同じ大会の複数モデル組み合わせ（アンサンブル）で top-5誤差 3.57% | He et al., 2015 |

これらは「その大会・その年の記録」です。今の最新・最高の数字ではありません。また「機械が人間より目がいい」と一般化してはいけません。ImageNet で訓練した人が top-5 で約 5.1% まちがえた、という報告もありますが、ルールも見る枚数も限られた比較です（Russakovsky et al., 2015）。

### 4.4 CNN 以外のやり方（いちばん大事な違い）

普通の全結合ネット（ぜんぶのマスを全部つなぐ網）は、絵の近くの点どうしが仲間、という性質をあまり使いません。つなぎが多くなりすぎます。CNN は近くだけ見て、同じ虫眼鏡を使い回します。

2020年ごろからは Vision Transformer（ビジョン・トランスフォーマー。ViT。絵を小さな四角に切って、遠く同士の関係も一度に見る仕組み）も使われます（Dosovitskiy et al., 2020）。今の写真アプリが必ず CNN とは限りません。

## 5. CNNは何に使われているの？

**「絵を読む AI」は、写真の整理、医療の手伝い、まちの調査など、いろいろな場所にあります。中身が CNN かどうかは、公開されていないことが多いです。**

下の例は「画像認識が使われている身近な話」です。授業では「CNN の考え方の延長にある」と伝え、製品名で断定しないでください。

### 5.1 身近な例

**写真アプリの整理**  
犬だけ、人だけ、と写真を集める機能があります。Apple は端末の中で人物をまとめる深層学習（しんそうがくしゅう。層の多い学習）を公表しています。Google フォトなどでも被写体の整理が一般的です。中の設計は各社で違い、古典的な CNN とは限りません。

**空港の顔認証ゲート**  
日本の空港では、パスポートの顔写真とゲートで撮った顔を照合する装置が使われています（例: 法務省の顔認証ゲート、パナソニックの発表など）。便利な一方で、顔はとても大切な個人情報です。知らないうちに記録・使い回しされないよう、決まりが議論されています。この資料では「便利だから何でも使ってよい」とは言いません。

**医療の画像の手伝い**  
内視鏡や肺の写真などで、病気の候補を見つけるプログラム医療機器があります。**お医者さんの代わりではありません。** 最終の診断は人が行います。

**航空写真で家を見つける**  
総務省の自治体向け AI ガイドブックでは、二時期の航空写真の違いから家の変化を見つける例（前橋市など）が紹介されています。税金の対象把握やまちづくりの効率に使う、という説明です。

### 5.2 「コンピュータはすごい？ 人間はすごい？」

| | 機械が得意なこと | 人が得意なこと |
|---|---|---|
| 速さ | 似た写真を大量に見る | 初めての場面で意味を考える |
| 疲れ | 同じ作業をくり返しやすい | 「おかしい」と感じる |
| まちがい | 見たことのない形で大きくはずすことがある | 文脈（前後の事情）で補う |

どちらが上、ではなく、得意分野が違います。

## 6. 自分でやってみよう！

**読んで終わりにせず、手を動かして「探す→まとめる→確かめる」を体験するのがいちばん分かります。**

### 6.1 学びのフェーズ（家庭・授業）

| フェーズ | 時間の目安 | 目標 | 成果物 |
|---|---|---|---|
| 1. 読む | 15〜20分 | CNN の一言定義が言える | まとめポイントの復唱 |
| 2. 紙の実験 | 1コマ | フィルタ走査が分かる | 3×3 の「縦線マップ」 |
| 3. 機械で体験 | 1コマ | 学習とテストの違いが分かる | 自分で撮った物の分類 |
| 4. 気をつける話 | 0.5〜1コマ | 過学習・偏り・プライバシーが言える | クラスの約束メモ |

**体制の例**: 進行は担任または理科・総合の担当。実験の見守りは保護者または、いれば ICT 支援員。支援員がいなくても、教員用パソコン1台のデモだけで第3フェーズの目標は達成できます。個人の顔写真は使わない（第6.4節）。

**前提**: かけ算の意味が分かること。パソコンは必須ではない（紙だけでも第6.2節はできる）。学校のネット制限で外部サイトが使えない場合は、紙の実験だけで完了してよいです。

### 6.2 家庭・授業：紙とえんぴつの虫眼鏡

1. 方眼紙に、猫や数字の「1」を大きなマスで描く。
2. 3マス×3マスの窓を切り、絵の上を1マスずつずらす。
3. 「この窓に縦線がある？」を 0（ない）か 1（ある）でメモする。
4. メモの表が、特徴マップの考え方です。

対象の目安: ★★☆（3年生から）。先生が最初の1回をお手本で動かすと安心です。

### 6.3 授業：絵当てゲーム（段階的な認識）

最初は「線だけ」、次は「耳だけ」、最後に全体を見せて当てます。CNN が浅い層から深い層へ進む体験になります。わざとぼかした絵で、人と機械の得意・不得意を話し合う「まちがい探し」も有効です。

### 6.4 コンピュータで体験するとき

Google の Teachable Machine（ティーチャブルマシン。カメラの映像で簡単な分類を試せるウェブ道具）は、CNN の気持ちを味わう入口になります。URL や仕様は変わることがあります。検索して最新を確認し、**必ず大人と一緒に**使ってください。

**プライバシーと著作権**: 顔・制服の名札・家の中が写る写真は使わないでください。花、消しゴム、ペットボトルなど、自分で撮った物か、先生が用意した使ってよい素材が安全です。インターネットで検索した他人の写真は、著作権（ちょさくけん。作った人の権利）があるので、勝手に学習に使わないでください。ツールの学習が自分のパソコンの中だけで終わるか、保存・書き出しのときに外部へ送るかは、公式の説明が変わります。授業の前にプライバシーポリシー（きまりの文章）を大人が確認してください。学校のルールと保護者の許可を守ってください。

**代替**: サイトに入れないときは、第6.2節の紙実験だけで十分です。手元の写真アプリの「被写体で探す」機能を、大人のスマホで見せるだけでも「機械が種類を付ける」体験になります。

### 6.5 どうやって上手か確かめるか（評価・検証）

**学習に使っていない絵（テストデータ）で試すことが、カンニングを防ぐいちばん大切なルールです。**

| テスト項目 | 合格の目安（授業用） | 測り方 |
|---|---|---|
| 正答率（せいとうりつ。当たった割合） | 学習に使っていない写真でも、でたらめより明らかに高い | 10枚中何枚当たったか |
| 学習とテストの分離 | テストの写真を学習に入れていない | チェックリストで確認 |
| 過学習の気配 | 練習は100点なのに、新しい写真だけ弱い、になっていない | 練習用と新しい写真を比べる |
| プライバシー | 顔・名札を使っていない | 活動前の約束 |

混同行列（こんどうぎょうれつ。「猫を犬とまちがえた」などを表にしたもの）や、精度・再現率（せいど・さいげんりつ。まちがいと見逃しのバランス）という言葉は、5〜6年生や教員向けの発展です。低学年は「新しい写真でも当たるか」だけで十分です。

受け入れの考え方: 子どもが「虫眼鏡で探して、最後に種類を言う」「練習用とテスト用を分ける」を自分の言葉で言えれば、この資料の目標は達成です。大会の誤差 0.95% を授業で再現する必要はありません。

## 7. CNNが苦手なこと・気をつけること

**CNN は万能ではありません。便利さの隣に、まちがいとプライバシーがあります。**

| リスク | 起こりやすさ | 影響 | 対策 |
|---|---|---|---|
| 過学習（おぼえすぎ） | 中 | 新しい問題だけ弱い | テスト用の絵を別に残す。同じ問題集ばかり使わない |
| データの偏り | 中〜高 | 特定の色・種類だけ苦手 | いろいろな例で練習する。不公平がないか大人が見る |
| 誤認識 | 中 | 自信ありげでもはずす | 医療・安全など大事な場は人が最終確認 |
| だまされやすさ | 研究上は重要 | 人が気づかない変化で判断が変わることがある | **作り方は書かない。** 「完璧ではない」と知る |
| プライバシー | 運用次第で高 | 顔や体の情報が漏れる・目的外に使われる | 顔写真を安易に学習に使わない。法律と学校の決まりを守る |
| 「人間より目がいい」と言いすぎ | 説明のとき高 | 機械を信じすぎる | 数字の条件を見る。この資料の歴史記録を最新扱いしない |

**だから、機械の答えを確かめるのは人の仕事です。**

日本では個人情報保護法など、顔や体の情報の使い方に決まりがあります。学校にカメラを置く話は、便利さだけでなく同意と目的の説明が必要です。

## 8. まとめ

**CNN は、小さな虫眼鏡（フィルタ）で絵の特徴を何度も探し、だんだん種類を決める仕組みです。段の重ね方・練習の仕方・気をつけることもセットで覚えてください。**

この資料で学んだこと:

1. 絵はコンピュータの中では色の数字である。
2. 畳み込み → プーリング →（繰り返し）→ 全結合 → 点数、という流れがある。
3. 手前では線や色、奥では部品に近い特徴を探しやすい。深くする工夫も研究されている。
4. LeNet-5 や AlexNet は、絵を読む研究の歴史の目印である（当時の記録）。
5. 身の回りに画像認識はあるが、中身の断定はしない。
6. テスト用の絵で確かめる。顔などの個人情報はむやみに使わない。

まだ残る問い: CNN はこれから Vision Transformer などとどう役割分担するのか。人と機械は、どの仕事を分担するのがよいか。興味がわいた人は、付録の用語集と参考資料へ進んでください。

## 付録

### A. 保護者・教員向け補足ガイド

**たとえと事実**

- 虫眼鏡・はんこ・虫取り網は比喩です。実装は多次元配列の演算です。
- ソフトマックスの出力は確率分布の形をしていますが、校正（calibration。点数と本当の当たりやすさの一致）されているとは限りません。
- Hubel & Wiesel / ネオコグニトロンは歴史的示唆であり、現代 CNN が皮質と同じ処理をしている証明ではありません。

**単元設計の例（45分×2）**

- 1コマ目: 第1〜3章の読み聞かせと紙の3×3実験。評価は「フィルタをずらす動作ができる」。
- 2コマ目: 第5〜7章。写真アプリのデモ（任意）と、使ってよい写真／いけない写真の約束作り。

**準備物**: 方眼紙、はさみ、鉛筆。任意で教室PCまたは教員用1台。ネットが使えなくても成立します。

**数値の扱い**: 本文の誤差は論文当時のベンチマークです。子どもが「今も 0.95%」と暗記しないよう、必ず「昔の大会の記録」と添えてください。

**顔・体の情報と法律（教員・保護者向け）**: 日本の個人情報保護法では、顔や指紋など体の特徴から個人を識別できる情報は、特に慎重に扱う対象です（要配慮個人情報などの整理。改正後の条文・ガイドラインは授業前に最新を確認）。空港の顔認証は、目的と同意の枠組みがある公的な手続きの例です。学校の実験では、児童の顔を学習データにしない、という運用を推奨します。

### B. 用語集

| 用語 | 子ども向け | もう少し正確に |
|---|---|---|
| CNN | 絵を読むのが得意な学習の仕組み | 畳み込み層を持つ順伝播型ニューラルネットワーク |
| フィルタ | 小さな虫眼鏡 | 学習可能なカーネル重み |
| 特徴マップ | 探し結果のメモ | 畳み込みの活性化マップ |
| プーリング | メモを小さくまとめる | max / average pooling など |
| 全結合層 | 判定席 | 平坦化後の dense 層 |
| ソフトマックス | 点数をパーセントっぽくする | ロジットを正規化した出力。真の確率とは限らない |
| 過学習 | 同じ問題集だけ満点 | 汎化性能の低下 |
| 重み | 虫眼鏡の中の数字 | 学習パラメータ |
| 誤差逆伝播 | まちがいを後ろから直す | 勾配を逆向きに伝播して更新 |
| 深層学習 | 段の多い学習 | 多層ニューラルネットによる表現学習 |
| MNIST | 手書き数字の問題集 | 6万枚訓練＋1万枚テストが標準規模 |
| ImageNet / ILSVRC | 大きな写真大会 | 大規模ラベル付き画像と競技 |
| ViT | CNN のあとに出てきた別の絵の読み方 | パッチ列に対する Transformer |
| パラメータ | 機械が覚える数字の個数 | 重みとバイアスの総数 |
| テストデータ | 練習に使っていない問題 | ホールドアウト評価用データ |

### D. 想定Q&A

**Q1（技術）: CNN は人間より目がいいの？**  
**A1**: ある大会のルールでは、機械の数字が人の数字に近づいたことがあります。でもそれは限られた比較です。初めての場面の意味理解では、人が強いことが多いです。どちらが上、ではありません。

**Q2（学習）: どうやって「猫」という言葉を知るの？**  
**A2**: 絵と名前の札をセットでたくさん見せます。言葉の意味を人が教えるデータがあって、はじめて分類できます。

**Q3（実装）: フィルタはどう決まるの？**  
**A3**: 最初はほぼでたらめです。答え合わせをくり返し、当たりやすい数字に少しずつ変わります。

**Q4（リスク）: CNN はうそをつくの？**  
**A4**: 故意のうそというより、学習の偏りや見たことのない形でまちがえます。医療や安全では人が最終確認します。

**Q5（運用）: ゲームのキャラは見分けられる？**  
**A5**: 練習にその絵が入っていれば当たることがあります。まったく初めてのキャラは苦手です。

**Q6（保護者）: CNN と AI は同じ？**  
**A6**: AI の一部です。機械学習、その中の深層学習、さらに画像向きの一手法、が CNN です。

**Q7（授業）: 子ども一人で Teachable Machine は？**  
**A7**: 推奨しません。カメラと外部送信の可能性があるため、大人同伴、顔写真なしで使ってください。使えない環境では紙実験で代替します。

**Q8（コスト・体制）: 特別な予算は必要？**  
**A8**: 紙と鉛筆だけで第1目標は達成できます。PC は任意です。外部サービスの契約は不要です。

**Q9（偏り）: データの偏りはどうする？**  
**A9**: 色・種類・向きを広げた例を集めることと、できたあと実データで様子を見ることが基本です。授業では「白い猫だけ練習したら？」と問うだけで十分です。

**Q10（リスク）: 機械はだまされるの？**  
**A10**: 人にはほとんど分からない小さな変化で、機械の答えが変わることがあります（研究で知られています）。道路の標識に細工をする具体的な方法は、この資料では書きません。だからこそ、安全に関わる判断は人が最終確認します。
