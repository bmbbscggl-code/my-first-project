## エグゼクティブサマリー

> **この資料の目的**: スマホで3分から遊べるG検定学習ゲームの要点と、公式試験との境界を最初に伝える。

**G検定を、スマホで、楽しく、3分から。** 公式過去問は使わず、公開シラバスの10分野に沿ったオリジナル80問で、基礎を口語の解説つきで体験できます。合格水準との対応はJDLA非公表のため保証しません。

**結論・提言**（90秒フック）:

- 遊びのループは「タイトル → 学習マップ → クイズ → 解説 → 結果」の5画面。1問1画面、制限時間なし。
- ステージはシラバス10分野に対応。初心者向けの呼び名（例: 「AIって何だろう？」）を使う。
- 各問の直後に、たとえ話の解説と「なるほどポイント」を出す。
- **JDLA非公式**。問題は公式過去問・公式例題の複製ではない。合格を保証しない。
- 短縮模擬（20問）の「練習目標70%」はゲーム内目標。本試験の合格基準は非公表。

**対象読者への影響**: 学習者は `game/index.html` を開けばすぐ遊べる。実装者は `game/` 配下の静的ファイルだけで配布できる。

## 1. 背景と課題

### 1.1 背景

G検定（ジェネラリスト検定、正式名称 JDLA Deep Learning for GENERAL）は、一般社団法人日本ディープラーニング協会（JDLA）が実施する、AI・ディープラーニングの活用リテラシー試験です（出典: [JDLA公式](https://www.jdla.org/certificate/general/)）。2026年のオンライン試験は100分・約145問、会場は120分・約145問。受験料は一般13,200円（税込）。合格基準点は公式非公表（出典: [G検定FAQ](https://www.jdla.org/g-qa/)）。直近のオンライン合格率はおおむね77〜83%です（各回の公式開催結果）。

直近のオンライン合格率は77〜85%程度、同時期の会場（Onsite）は64〜70%と低い回があります（2026#2〜#3の公式開催結果）。条件の違いは公式未説明のため参考値です。合格者アンケートでは学習時間の最多が30〜50時間（25.3%）です（出典: [学習の始め方](https://www.jdla.org/certificate/general/start/)）。通勤やスキマ時間向けの、軽い導入が不足しています。

### 1.2 課題・問題点

| 課題 | 現状 | 目標 | ギャップ |
|---|---|---|---|
| 入り口の広さ | シラバス10分野＋生成AIの新語 | 最初の3分で「今どこを学ぶか」が分かる | 公式テキストは重い |
| つまずき | 数理・生成AI・法律が混ざりやすい | 1分野6問・たとえ話解説 | 用語の丸暗記になりがち |
| 著作権 | 過去問の無断複製は差止め実績あり（2019年、JDLA） | オリジナル問題のみ | 市販の「過去問風」はリスク |

### 1.3 スコープ

**対象範囲**: スマホ縦持ちWeb、10ステージ学習、今日の5問、短縮模擬20問、まちがいノート、進捗の端末内保存。  
**対象外**: 公式過去問、145問フル模擬、合格保証、サーバー同期、課金。

## 2. 技術概要

### 2.1 システムの概要

インストール不要の静的Webアプリです。HTML / CSS / JavaScript のみ。問題データと採点ロジックはブラウザ内で完結します。

相棒キャラ「ニューロ」（神経細胞を模したマスコット）が、クリア数に応じて姿を変えます。連続正解で「連鎖」表示が出ます。

### 2.2 主要コンポーネント

| コンポーネント | 役割 | 技術 |
|---|---|---|
| `questions.js` | 10分野×8問＝80問 | オリジナル作問 |
| `engine.js` | 出題・採点・進捗 | Node.js（JavaScriptのサーバー側実行環境）でもテスト可 |
| `app.js` | 画面遷移 | 素のDOM（ブラウザが提供するページ操作API。外部ライブラリ不使用） |
| `audio.js` | 効果音 | Web Audio |
| `style.css` | 縦持ち・セーフエリア | 最大幅480px |

### 2.3 アーキテクチャ

```
タイトル ─► 学習マップ ─► ステージ導入 ─► クイズ ─► 解説 ─► 結果 ─┐
    │            │                                         │
    │            ├─ 今日の5問 ─────────────────────────────┤
    │            ├─ 短縮模擬（確認ダイアログ必須）──────────┤
    │            └─ まちがいノート                           │
    └─ このゲームについて（詳細免責＋公式リンク）            │
                                                              └─► マップへ戻る
```

進捗は `localStorage`（ブラウザが端末内にデータを保存する仕組み）のキー `neuroquest-v1` に保存します。

## 3. 詳細設計・仕様

### 3.1 ステージ対応

| # | ゲーム内名 | シラバス分野 | ボス |
|---|---|---|---|
| 1 | AIって何だろう？ | 人工知能とは | フレームおばけ |
| 2 | AIの歴史をたどろう | 人工知能をめぐる動向 | 冬眠ドラゴン |
| 3 | 機械はどうやって学ぶ？ | 機械学習の概要 | 過学習オオカミ |
| 4 | ディープラーニングの仕組み | ディープラーニングの概要 | 勾配消失ゴースト |
| 5 | ネットワークの部品を知ろう | 要素技術 | 畳み込みスフィンクス |
| 6 | AIは何ができる？生成AI編 | 応用例 | 生成の鏡 |
| 7 | 会社でAIを使うには | 社会実装 | リーク海賊 |
| 8 | 苦手克服！数字とAI | 数理・統計 | 分散おばけ |
| 9 | AIと法律のキホン | 法律と契約 | 契約ゴーレム |
| 10 | AIを正しく使うために | 倫理・ガバナンス | 公平の番人 |

各プレイはプール8問から6問を無作為抽出。前ステージで正答率60%以上（星1以上）で次を解放。第1ステージは最初から開放。

**短縮模擬を20問にした理由**: 構成アウトラインでは本試験に近い145問・100分を将来仕様として書いた。v1.0の問題プールは80問のため、重複なしの145問は作れない。初心者が10分前後で全分野を一周できることも優先し、10分野×2問の短縮形式にした。145問フル模擬はプールを300問以上に増やしたあとの将来項目。

### 3.2 画面仕様（実装済み）

- **タイトル**: 免責4点を固定表示。ボタン高さ52px以上。
- **マップ**: 10ステージ縦スクロール。未解放は錠。ミュート切替あり。
- **クイズ**: 4択・縦並び・最小高さ56px。タイマーなし。
- **解説**: 正誤バナー、楽しい解説、なるほどポイント、分野タグ。
- **結果**: 正解数、コメント3段階、ミス一覧。
- **短縮模擬ゲート**: 練習目標と非公式の確認をタップしないと開始できない。
- **まちがいノート**: 直近最大40問。
- **About**: 詳細免責と公式サイトリンク。

**v1.0スコープ外（将来項目）**

| 機能 | アウトライン上の位置 | v1.0 |
|---|---|---|
| 用語集（全文検索） | 4-7 | 未実装 |
| フォントサイズ3段階 | 4-8 | 未実装 |
| SNSシェア | 4-5 | 未実装 |
| 145問・100分模擬 | 4-6 | 未実装（20問短縮のみ） |
| サーバー同期 | 5-1 Phase 3 | 未実装 |

About画面にも、タイトル画面と同趣旨の「合格保証なし／基準非公表」を置く。

### 3.3 採点ルール（ゲーム内）

| 正答率 | 星 | コメント |
|---|---|---|
| 80%以上 | ★★★ | 完璧 |
| 60%以上 | ★★ | いい感じ |
| 1問以上 | ★ | もう一回 |
| 0% | ☆ | もう一回 |

短縮模擬の練習目標は70%。これはJDLAの合格基準（非公表）を写したものではない。ステージ解放の60%より一段高い「もう一度地図を見直す目安」として、ゲームデザイン上選んだ。60%や80%でもよいが、学習者の会話でよく聞く目安に寄せ、画面上では必ず「本試験基準ではない」と併記する。

## 4. 実装計画

実装済み（v1.0）:

1. 遊びループと免責
2. 10ステージ＋80問（アウトライン想定の約139問から削減。各分野の最重要概念を8問で押さえるMVP。次フェーズで15〜18問へ拡充予定）
3. 今日の5問、短縮模擬20問、まちがいノート
4. `node game/tests/engine.test.js` による問題検査と採点テスト

配布: `python3 -m http.server` などで `game/` を配信。スマホのホーム画面追加（standalone）はマニフェストで対応。

## 5. 評価基準・検証方法

| 評価軸 | 指標 | v1.0の結果 |
|---|---|---|
| 学習カバレッジ | シラバス10分野 | 各8問でカバー（コード確認済み／学習効果は未検証） |
| 問題整合 | id一意・4択・解説必須 | 自動テストPASS |
| 模擬の分野バランス | 10分野×2問 | 自動テストPASS |
| 免責の初出 | タイトル画面 | 実装済み（ユーザー誤認率は未検証） |
| 公式基準との混同防止 | 模擬ゲート＋結果注記 | 実装済み（ユーザー誤認率は未検証） |

「実装した」ことは「学習者が基礎を身につけた」ことの証明ではありません。βテスト（初心者10名程度）で免責誤認率と1ステージ所要時間を測る計画は将来項目です。目安の「3分」は6問×約30秒の推算です。

## 6. リスクと対策

| リスク | 重大度 | 対策 |
|---|---|---|
| 公式問題との偶発的類似 | 高 | 公開一般知識のみで作問。公式例題ページの文面は複製しない |
| 練習目標＝合格基準と誤解 | 高 | タイトル・模擬ゲート・結果の3箇所で打ち消し |
| シラバス改訂 | 中 | 問題を `questions.js` で差し替え可能 |
| 本ゲームでは合格できない期待 | 中 | 「合格水準」という語を本文で使わない。公式テキストを推奨 |
| 問題の技術レビュー未実施 | 中 | v1.1までにG検定合格者3名以上の確認を推奨。v1.0は一般知識の初歩に限定 |
| シラバス最新版との差分 | 中 | 調査時点の公式PDFはv1.4表示。本問は公開分野名と一般知識ベース。追加語（SARSA等）は未網羅の可能性。改訂時は `questions.js` を差し替え |
| 法令解説の陳腐化 | 中 | 法律問は概説に留め、専門家相談を注記。年次で見直す |

## 7. 付録

### 7.1 免責文（実装原文の要約）

本ゲームはJDLA非公式です。問題は公式過去問・公式例題の複製ではありません。ゲーム内の合格ラインは練習目標で、本試験の合格基準（非公表）とは違います。合格を保証しません。問題は公開シラバスの分野名と一般知識に基づき、最新改訂の全キーワードを網羅していない可能性があります。

### 7.2 起動とテスト

```bash
python3 -m http.server 8765 --directory /workspace
# http://127.0.0.1:8765/game/index.html
node game/tests/engine.test.js
```

### 7.3 想定Q&A

1. **公式の過去問ですか？** — いいえ。オリジナルです。
2. **70%で本番も受かりますか？** — 分かりません。合格基準は非公表です。70%はステージ解放（60%）より高いゲーム内目安です。
3. **本番は何問ですか？** — 2026年オンラインは約145問・100分です（公式）。
4. **データはどこに保存されますか？** — この端末のブラウザ内だけです。
5. **E資格の勉強になりますか？** — 実装寄りのE資格（エンジニア向け）とは目的が違います。基礎の導入には使えます。
6. **音が出ます。** — マップ右上の ♪ でミュートできます。
7. **間違えた問題は？** — まちがいノートに残ります。
