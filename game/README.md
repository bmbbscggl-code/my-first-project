# 星詠みの弾幕

スマホ縦持ちブラウザ向けのファンタジー弾幕シューティングです。インストール不要。宇宙船や SF は出てきません。

## 遊び方

1. `index.html` をブラウザで開く（ローカルなら `npx serve game` など）
2. **はじめる** を押す
3. 画面をドラッグ（またはマウス）して精霊を動かす
4. 攻撃は自動連射。ボムはありません
5. 当たり判定は自機中央の赤い点。弾の隙間をすり抜けて避ける
6. 雑魚ウェーブのあとボス「星蝕の巫女」を撃破するとクリア

1プレイはおよそ 3〜5 分。残機は 3。ハイスコアはブラウザの `localStorage` に保存されます。

## 操作上の注意

- 指の下に自機が隠れないよう、タッチ位置より上に追従します
- ノッチ・ホームインジケータ（セーフエリア）を考慮しています
- 右上の ♪ でミュート（設定は保存されます）
- デスクトップでもマウスで遊べます

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | エントリ |
| `css/style.css` | レイアウト・セーフエリア・オーバースクロール防止 |
| `js/core.js` | 判定・スコア・ウェーブ（Node でもテスト可） |
| `js/audio.js` | Web Audio の簡易効果音 |
| `js/game.js` | 描画・入力・敵/ボス |
| `tests/core.test.js` | コアロジックのユニットテスト |

```bash
node game/tests/core.test.js
```

ブラウザ自動確認（任意、`puppeteer-core` と Chrome が必要）:

```bash
python3 -m http.server 8765 --directory .
# 別ターミナル
GAME_URL=http://127.0.0.1:8765/game/index.html node game/tests/e2e.mjs
```

検証用クエリ: `?quick=1` でウェーブ時間を圧縮します。
