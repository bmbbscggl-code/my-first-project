# ニューラルクエスト — G検定への冒険

スマホ縦持ちブラウザ向けの学習ゲームです。インストール不要。
一般社団法人日本ディープラーニング協会（JDLA）の **G検定（JDLA Deep Learning for GENERAL）** の公開シラバス分野に沿った、**オリジナル問題**で遊びます。

**JDLA非公式**です。公式過去問・公式例題は使っていません。合格を保証しません。ゲーム内の70%は練習目標で、本試験の合格基準ではありません。

## 遊び方

1. `game/index.html` をスマホまたはブラウザで開く
2. 免責を読んだら **冒険をはじめる**
3. 学習マップのステージを順に解く（各6問、制限時間なし）
4. 答えた直後に、たとえ話の解説と「なるほどポイント」が出る
5. 60%以上で次のステージが開く
6. **今日の5問** は日付で変わるミニ冒険
7. **短縮模擬（20問）** は10分野×2問。ゲーム内の練習目標は70%（本試験の合格基準ではない）

相棒のニューロは、クリアしたステージ数と模擬の達成で姿が変わります。間違えた問題は **まちがいノート** に残ります。進捗はブラウザの `localStorage` に保存されます。

## 本番試験との違い

| | このゲーム | G検定（オンライン・2026年） |
|---|---|---|
| 問題 | オリジナル80問 | 約145問（公式） |
| 時間 | 制限なし | 100分 |
| 合格 | 練習目標70%（ゲーム内） | 基準点は非公表 |
| 著作権 | 独自作問 | 試験問題の著作権はJDLA |

最新の試験情報は [JDLA公式](https://www.jdla.org/certificate/general/) を見てください。

## 起動

```bash
python3 -m http.server 8765 --directory /workspace
# http://127.0.0.1:8765/game/index.html
```

## テスト

```bash
node game/tests/engine.test.js
```
