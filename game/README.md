# スターヴァイパー / STAR VIPER

ファミコン版『グラディウス』へのオマージュとして作った、ブラウザ向け横スクロールシューティングです。スマホのタッチ操作で遊べます。

## 遊ぶ

ブラウザでどれか一つを開いて、画面をタップ／クリックする。

- ワンファイル版: `game/star-viper.html`（このファイルだけ開けば遊べる）
- 分割版: `game/index.html`
- オンライン: https://raw.githack.com/bmbbscggl-code/my-first-project/cursor/star-viper-shooter-c818/game/index.html

ローカルサーバ:

```bash
python3 -m http.server 8080 --directory game
```

## 操作

| デバイス | 移動 | ショット | パワー発動 |
|---|---|---|---|
| スマホ | 画面をドラッグ | 自動連射 | 下の POWER ボタン |
| PC | 矢印 / WASD | 自動連射（Zでも可） | X / Shift |

ポーズは `P` または PAUSE ボタン。ミュートは `M`。

## ルール（グラディウス準拠）

赤いカプセルを取ると、画面下のパワーメーターが進みます。

`SPEED → MISSILE → DOUBLE → LASER → OPTION → ?`

欲しい欄が点灯したタイミングで POWER を押すと装備します。被弾すると装備はすべて消えます。`?` はシールド（3発まで耐える）です。

隠しコマンド: `↑↑↓↓←→←→BA`（コナミコマンド）

## ステージ

1. 火山星域 — 空中戦のあと、地形と火山
2. モアイ遺跡 — 石像がリング弾を撃つ
3. 要塞 — 砲台とコアボス
